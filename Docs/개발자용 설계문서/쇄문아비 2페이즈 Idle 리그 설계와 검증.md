`Assets/4.Sprite/Test/`의 합성본·몸통·왼팔·오른팔 PNG 4개를 `Assets/5.Animation/Swaemunabi_Phase2/Source/`에 복사했습니다. PNG 바이트는 원본과 같습니다. 원본 PNG와 원본 임포트 설정은 유지합니다.

분리 PNG를 원본에 맞춘 좌상단 기준 이동은 몸통 `(30,-4)`, 왼팔 `(-50,22)`, 오른팔 `(90,36)`픽셀입니다. 분리 이미지만 합치면 41픽셀 누락·59픽셀 겹침·4픽셀의 알파 차이가 있었습니다. 이를 새로 그리는 대신 합성본 사본의 픽셀을 몸통과 양팔의 메시 영역으로 분리했습니다. 불투명 픽셀 16,831개가 중복 없이 정확히 한 부위에 배정됩니다. 팔에 섞인 옷자락 영역은 몸통으로 유지합니다.

합성본 사본의 TextureImporter는 Multiple / Point / Uncompressed / PPU 100 / Mipmap off입니다. 256×256 전체 영역을 공유하는 Body·LeftArm·RightArm·OriginalReference Sprite를 가지며, 공통 피벗은 좌하단 기준 `(135,24)`픽셀입니다. 실제 편집은 Sprite Editor 데이터 공급자로 적용했고 `.meta`를 직접 편집하지 않았습니다.

메시는 불투명 픽셀의 경계를 보존하는 촘촘한 격자입니다. 몸통 12,155, 왼팔 3,321, 오른팔 2,927정점, 총 18,403정점·33,662삼각형입니다. CPU 변형으로 검증했으며 많은 개체의 동시 등장 성능이나 최종 빌드 성능은 검증 범위 밖입니다. 이후 최적화 시 픽셀 경계와 관절 최대 자세를 다시 비교해야 합니다.

## 공용 리그

최초 쇄문아비 리그이며 8개 뼈를 세 SpriteSkin이 공유합니다. 프리팹 루트 위치는 원점입니다. 비교 씬에서만 왼쪽 `x=-1.6`으로 배치합니다.

```text
Root
  Body
    UpperArm_L
      Forearm_L
        Hand_L
    UpperArm_R
      Forearm_R
        Hand_R
```

Root는 전체 배치를 담당하고 Idle에서 움직이지 않습니다. Body는 0~1.8픽셀 상승합니다. 어깨·팔꿈치·손 위치에서 2관절 계산으로 손 기준점을 유지하며, 계산 결과를 .anim의 회전 키로 저장했습니다. 손 회전도 보정하여 손끝의 실루엣을 유지합니다. 단단한 상부 장식은 몸통과 함께 움직이며 별도의 휘어지는 뼈를 추가하지 않았습니다.

정점 가중치는 몸통과 팔 사이, 팔꿈치, 손목에 연속적으로 섞고 합을 1로 유지합니다. 초기의 급격한 영역 분기는 제거했습니다. SpriteSkin의 Root Bone과 Bone Transforms 8개, 임포트된 뼈와 바인드 포즈 8개가 일치합니다. 다른 캐릭터의 HeosuguiRigDemo는 변경하지 않습니다.

## 클립과 컨트롤러

- `Clips/Swaemunabi_Phase2_Idle.anim`: 2.4초, 30fps, loopTime=true, root motion 없음.
- `Root/Body`의 위치 X/Y/Z와 팔 6개 뼈의 `localEulerAnglesRaw.z`: 총 9곡선.
- 움직이는 곡선은 73개 키, 0~72프레임입니다. 루프 양끝의 값과 접선을 맞췄습니다.
- `Controllers/Swaemunabi_Phase2_Preview.controller`: Idle 기본 상태 하나만 가지는 시험 전용 자산입니다.
- Animator가 .anim을 재생하며 반복 애니메이션 스크립트, 런타임 IK, 게임 로직 의존성은 없습니다.
- 향후 다른 클립은 이 프리팹의 뼈 이름·경로·바인드 포즈를 유지하여 추가합니다.

## 실제 검증

별도 비교 씬에서 Unity Play를 실행하고 실제 Game 뷰를 관찰했습니다. 화면 캡처는 `Validation/04_final_exhale.png`, `05_final_inhale.png`, 연속 재생 측정은 `play_metrics.json`에 있습니다. 측정용 콜백은 애니메이션을 조작하지 않고 관찰한 뒤 스스로 해제했으며 프로젝트 런타임 스크립트로 남기지 않았습니다.

| 몸통 상승 폭 | 1.79999 원본 픽셀 |

| 손 고정 정점 최대 이동 | 0.000223 원본 픽셀 미만 |

최대 길이 비율은 관절의 미세한 변형을 포함하며, 모든 변에 대한 변형률 상한이나 전체 포즈 공간의 보장은 아닙니다. 현재 Idle의 모든 정점 가중치 합을 확인했고, 실제 재생 중 손 고정 정점은 매 관찰에서, 삼각형은 일정 간격으로 검사했습니다.

처음 재생에서는 부분 위치 곡선 때문에 몸통 X가 기본값으로 바뀌어 고정 X/Z 곡선을 추가했습니다. 초기 가중치 경계에서는 일부 삼각형이 뒤집혀 연속 가중치로 수정하고 2주기를 다시 검증했습니다. 시험 카메라에는 URP Additional Camera Data를 추가하여 카메라 경고를 해소했습니다.

## 남은 범위

현재 대상에는 기존 동작 클립이 없어 기존→새→기존 전환 검증을 할 수 없습니다. 다른 클립이 생기면 동일 프리팹에서 경로·바인드 포즈·접지와 전환을 확인해야 합니다. 오른쪽 비교 대상은 단일 정적 원본이며 기존 애니메이션 재현을 의미하지 않습니다. 큰 회전·가려진 신체·방향 전환에는 추가 원화나 원본 프레임 병행이 필요합니다. 도트 윤곽의 서브픽셀 변화는 작은 호흡에서도 일부 남습니다.

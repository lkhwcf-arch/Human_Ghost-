## 1. 읽는 기준

```mermaid
flowchart LR
    A[현재 작업] --> B[최신 통합 안내·현황]
    B --> C[기능 설계·사용 안내]
    C -->|이유와 이전 결과가 필요할 때| D[구버전 원문·날짜별 기록]
```

원문을 보존하고 최신 설명만 간결하게 갱신합니다. 당시 담당·검사 수치·미공급·고정값 설명은 현재 지시가 아닙니다. 구버전 파일을 새 구현 기준으로 배포하지 않습니다.

## 3. 날짜별 이력과 미사용 기능

날짜가 붙은 QA·PNG 압축·리소스 절감 문서는 [통합 안내의 날짜별 목록](../전체%20개발%20문서%20통합%20안내.md#8-날짜별-검증-이력-목록)에서 과거 근거로 분류합니다. 해당 기록은 당시 입력과 기준으로만 유효합니다.

현재 미사용이 확인되지 않은 기능은 삭제·폐기 목록에 올리지 않았습니다. 특히 플레이어 경사 적용은 보류이며 제거된 기능이 아닙니다. NPC의 수동 배치 제안 일부와 Rigidbody2D/Capsule 전환 후보는 현재 채택된 구현과 다르므로 경사·NPC 최신 구현 절을 따릅니다.

개선사항은 [개선 검토](../개선%20검토/코드%20구조와%20반복·재귀%20개선%20검토.md)로 분리하며 구버전에 보관했다는 이유로 수정 완료 처리하지 않습니다.

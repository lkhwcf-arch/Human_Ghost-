## 요청 한 줄

지금 잔불·빙판은 `GameplayPreview.Fields.cs`의 `ShowFieldAreas()`가 흰 1×1 스프라이트를 색칠해서 단색 사각형으로 그립니다. 이 사각형 대신 아래 그림을 그려 주세요. **판정(피해·넉백 2배 범위)은 지금 그대로 두시면 됩니다.**

- PPU 192는 `_worldUnitsPerTile = 1`(GameplayPreview 씬 값) 기준으로 1칸 = 192px입니다.
- 배경은 투명(알파)입니다. 색 덧칠(`renderer.color`)은 흰색(1,1,1,1)으로 두어야 원래 색이 나옵니다.

## 그리는 방법 (제안)

**잔불:** 자리 1곳당 `FieldFire_Debris` 1장. 너비를 자리 Width(지금 2칸)에 맞추고 세로는 비율대로 늘려 주세요. 바닥선(자리 Y)에 아래쪽이 닿게 놓으면 됩니다. 지금 사각형 높이(0.2칸)보다 그림이 조금 높은데, 판정은 그대로 0.2칸이어도 괜찮습니다.

**빙판:** SpriteRenderer `drawMode = Tiled`로 `FieldIce_Middle`을 자리 너비만큼 반복하고, 양끝에 `FieldIce_Left`·`FieldIce_Right`를 붙여 주세요. 끝 조각은 자리 안쪽으로 겹쳐도 됩니다(판정 범위는 자리 Width 그대로). 높이 0.22칸이라 지금 사각형(0.2칸)과 거의 같습니다.

**정렬 순서:** 지금처럼 플레이어와 같은 정렬 레이어, 맵 위쪽 순서면 됩니다. 몬스터·플레이어 발이 그림 위로 오게 하려면 플레이어보다 한 칸 낮춰도 됩니다.

## 판정 확인 결과

피해·넉백 범위는 `ConnectFields()`에서 자리 X·Width로 만든 `Bounds`(높이 0.2칸)로 계산하고, `FieldObjectController`는 이 Bounds만 봅니다. 그림 크기와 상관없으므로 그림을 바꿔도 빙판 끝·구덩이 가장자리 판정은 달라지지 않습니다.

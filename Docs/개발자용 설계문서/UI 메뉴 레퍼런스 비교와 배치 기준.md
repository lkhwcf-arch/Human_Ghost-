# UI 메뉴 레퍼런스 비교와 배치 기준

2026-11-13. 기존 아트·기능을 유지하며 읽는 순서와 클릭 영역을 정렬했습니다. 아래 수치는 인귀의 1920×1080 기준 배치안이며 다른 게임에서 실측해 복사한 값은 아닙니다.

## 옵션 이미지 누락과 아틀라스

이전 준비 단계에서 OptionsUI를 패킹한 뒤 Include in Build를 꺼두었고 별도 지연 로더가 없었습니다. 실제 Play에서 OptionsUI atlasRequested 미처리 경고를 확인했습니다. Unity는 이 설정을 끄면 런타임에서 아틀라스를 별도로 공급해야 합니다. [Unity 공식 설명](https://docs.unity.com/en-us/engine/6000.6/manual/unity2d/sprite/atlas/load-sprite-atlas-spriteatlasmanageratlasrequested)

현재는 Include in Build=true로 기본 자동 로드를 사용합니다. 배경/행/버튼은 제공 PNG의 임포트된 Sprite를 직접 참조하며 옵션 전용 8종으로 패킹 목록도 일치시켰습니다. 원본 PNG/meta는 보존했습니다. 이전 OptionsSlices 4개 자산은 현재 옵션에서 사용하지 않습니다. 별도 로더·폴링·게임 규칙 코드는 추가하지 않았습니다.

조회한 실제 키는 `98471_0`, `917_0`, `95877_0`, `8195_0`, `8771_0`, `811_0`, `04_ink_number_3_0`, `123_0`입니다. 현재 UI는 이 Sprite 참조를 자동 바인딩하며 별도 이름 검색을 반복하지 않습니다.

실제 Play에서 수동 아틀라스 로드 없이 자동 로드 → GetSprite(8개 이름) → 실제 Image.mainTexture의 같은 1024×1024 OptionsUI 페이지 연결 → 8종 픽셀 표시 → 실제 SettingsScreen 열기/렌더/닫기까지 55항목을 확인했습니다. 새 OptionsUI 요청 경고는 0건입니다. 게임 빌드를 실행했다는 뜻은 아닙니다.

## 검증 범위

- Edit 297항목: 실제 MapDohwagolTest의 PauseMenuHost 옵션 클릭 경로, 목재와 글자 순서·이미지 픽셀, 옵션 복귀·선택 표시 위치, NPC 4줄과 이름/넘김 분리·잘림, 1920×1080/1280×720/1920×1200/1024×768의 경계.
- Edit 60항목: 기존 옵션 변경·적용/취소·모달 차단·공유 참조·8종 바인딩. 자동 포함 true를 검증합니다.
- Play 55항목: 임시 UI 전용 씬의 실제 자동 로드·이름 조회·표시. 게임 저장·통계 기록 없이 확인하고 임시 씬/meta를 제거했습니다.
- 합계 412항목. 전체 맵 연속 Play·실행파일 빌드·실제 장치별 사용자 조작 검증과 구분합니다. 원본·맵·씬·데이터·게임 C# 소스는 보존했습니다.

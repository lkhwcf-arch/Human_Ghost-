# 쇄문아비 2페이즈 Attack1 개선본 확인 안내

> **아트 공동 기여:** 공급된 원본 아트의 제작·Git 외부 파일 전달에는 아트 담당자가 함께 참여했습니다. 아래 리소스 가공·프리팹·애니메이션·화면 연결 이력과 원본 제작 기여를 구분합니다. 미공급 전용 자산은 완료로 표기하지 않습니다. [작업자·커밋 기준](../개발자용%20설계문서/현재%20구현과%20검증%20현황.md#5-작업자별-역할과-git-근거)

기존 Attack1 시험 클립의 동작과 1.42초 타이밍을 유지하면서 **공격 전용 리그 사본의 메시·가중치**를 개선했습니다. 기존 Idle·Walk와 원본 리그는 변경하지 않았습니다. 게임 전투 코드에는 연결하지 않았습니다.

    A[전용 확인 씬 열기] --> B[동작 재생]
    B --> C[방향·관절·연결 확인]

1. `Assets/5.Animation/Swaemunabi_Phase2/Scenes/Swaemunabi_Phase2_Attack1_Refined_Test.unity`를 엽니다.
2. Play를 누릅니다. 왼쪽은 개선한 2페이즈 리그, 오른쪽은 기존 1페이즈 원화입니다.
3. 좌우 방향에서 각각 공격 세 번과 Idle·Walk 복귀를 확인합니다. 약 25초 뒤 Idle 상태에 머뭅니다.
4. 공격 포즈는 기존 `Clips/Swaemunabi_Phase2_Attack1_Study.anim`에서 편집할 수 있습니다. 파일 이름은 Study이지만 이번 개선 씬도 같은 클립을 그대로 사용합니다.

새 리그 프리팹은 `Prefabs/Swaemunabi_Phase2_AttackRig.prefab`, 스프라이트 사본은 `Source/Boss_Phase_2_AttackRig.png`입니다. 기준 경로는 위 캐릭터 폴더입니다. 기존 WalkRig 프리팹을 이 파일로 덮어쓰지 마세요.

## 개선된 부분

- 목재 팔의 어깨·팔꿈치 경계를 분리하고 기존 그림의 관절 주변 픽셀을 겹쳐 연결했습니다. 새 그림이나 무기를 만들지 않았습니다.
- 실제 공격 재생에서 오른팔의 최대 늘어남은 약 3.08배에서 1.00배로 줄었고, 메시 뒤집힘은 관측되지 않았습니다.
- 좌우 공격, 지지 왼손, 공격 후 Idle·Walk 복귀를 확인했습니다. 원본 공격 0.70~0.82초 타격 구간도 유지합니다.

## 남은 차이

메시 뒤집힘이 해소됐다는 것이 원화와 완전히 동일하거나 팀의 시각 검토가 끝났다는 뜻은 아닙니다. 2페이즈의 긴 팔과 높은 몸통, 04~05번 원화에서 가려지는 팔의 면, 옷자락의 실루엣 차이는 남아 있습니다. 관절이 겹치는 부분의 윤곽은 유연하게 늘어나는 대신 단단한 부품처럼 움직입니다. 지지 왼팔에는 회전에 따른 도트 늘어남이 남습니다.

새로 보이는 면의 디자인이나 가려진 팔의 최종 모습은 확정하지 않았습니다. 현재 근사 포즈를 팀에서 정한 원화로 취급하지 않습니다. 정확한 원화 일치를 원한다면 해당 면의 부위 그림과 팀 기준이 필요합니다.

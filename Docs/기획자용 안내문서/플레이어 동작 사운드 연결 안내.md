# 플레이어 동작 사운드 연결 안내

기준: 2026-11-09 사용자 요청표, 병합본 `9ba804e` 이후 로컬 연결. 음원은 `Assets/8.Audio/SFX`, 재생 목록은 `Assets/2.Model/Prefabs/Config/GameAudio.prefab`입니다. 원본 음원·CSV·JSON·엑셀·Sound 표는 수정하지 않습니다.

## 적용 범위

- 인게임의 기존 일반/전투 BGM 대신 `AMBIANCE_FIRE` → `Ambiance_Fire.wav`를 반복합니다. 공급 Sound 3001의 Category=2를 따르므로 옵션의 마스터·효과음 음량을 적용합니다. 타이틀은 별도 `HG_TitleSound.WAV`를 기존 음악 채널로 재생합니다.
- `HG_OJ_Fire`는 보류하며 재생 목록에 넣지 않았습니다. Idle에 별도 소리를 지정하지 않았습니다.
- Walk 3개·Run 2개는 같은 키에 여러 클립을 연결합니다. 효과음을 요청할 때마다 그 묶음 안에서 무작위로 하나를 고릅니다. 같은 클립이 연속으로 나올 수도 있습니다.
- 현재 플레이어는 상태별 대표 프레임 표시입니다. 걷기/뛰기나 신규 회피·뒤 구르기·두 번째 해체의 게임 동작 선택을 새로 구현하지 않습니다. 기존 동작에는 자동 호출을 연결하고 미선택 변형은 아래 키를 준비했습니다.

## 공급 Sound 표 연결

GameAudio 프리팹의 `_soundId` 23개가 공급 Sound 3001~3023을 소비합니다. 3001=불 환경음, 3002~3004=Walk, 3005~3006=Run, 3007~3023=아래 Hit부터 Save 순서입니다. 현재 모두 Category=2, Volume=10000, FadeInMs/FadeOutMs=1000이며 3001만 반복입니다. 표의 값을 재생에 반영하고 표 자체는 수정하지 않습니다. 3011 주소 철자는 명시적 프리팹 클립 연결로 처리합니다. 짧은 단발 음원은 두 페이드 합계를 실제 길이 안으로 비례 축소해 무음 종료를 방지합니다.

## Unity에서 확인하기

1. 현재 테스트 맵의 GameAudio 참조가 위 공용 프리팹인지 확인합니다. 씬의 재생 목록을 별도로 복사하지 않습니다.
2. 초기화·저장 복원이 끝난 뒤 GameplayPreview가 플레이어에 PlayerAnimationAudio를 연결합니다. 이전 HP를 복원하는 과정은 피격음으로 처리하지 않습니다.
3. 이동 중 벽에 막혀 실제 위치가 바뀌지 않거나, 공중·정지·일시정지 상태이면 자동 발소리 요청이 멈춰야 합니다. 자동 발소리 간격 0.5초는 현재 대표 프레임 확인용 임시값입니다.
4. 공격을 헛쳐도 휘두르기 소리는 나고, 적 수만큼 중복 재생하지 않아야 합니다. 피격·사망·해체의 예전 임시 중복 효과음은 해당 새 연결로 대체했습니다.
5. 최종 Animator의 발 접촉 이벤트를 연결하면 PlayerAnimationAudio의 **임시 자동 발소리**를 끕니다. `PlayAnimationSound`의 문자열 인자에 위 호출 키를 넣습니다. 기존 자동 호출이 있는 다른 동작도 애니 이벤트로 옮길 때 한쪽만 사용합니다.
6. Run·신규 Evade·Back_Roll·두 번째 Execute는 실제 애니 선택이 정해진 뒤 해당 이벤트에서 호출합니다. 현재 새 입력·상태·선택 규칙을 추가한 것은 아닙니다.

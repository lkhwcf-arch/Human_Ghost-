## 적용 범위

- 현재 플레이어는 CSV 상태별 스프라이트 클립으로 표시합니다. 걷기/뛰기나 신규 회피·뒤 구르기·두 번째 해체의 게임 동작 선택을 새로 구현하지 않습니다. 기존 동작에는 자동 호출을 연결하고 미선택 변형은 아래 키를 준비했습니다.

## Unity에서 확인하기

1. 현재 테스트 맵의 GameAudio 참조가 위 공용 프리팹인지 확인합니다. 씬의 재생 목록을 별도로 복사하지 않습니다.
2. 초기화·저장 복원이 끝난 뒤 GameplayPreview가 플레이어에 PlayerAnimationAudio를 연결합니다. 이전 HP를 복원하는 과정은 피격음으로 처리하지 않습니다.
3. 이동 중 벽에 막혀 실제 위치가 바뀌지 않거나, 공중·정지·일시정지 상태이면 자동 발소리 요청이 멈춰야 합니다. 자동 발소리 간격 0.5초는 현재 대표 프레임 확인용 임시값입니다.
4. 공격을 헛쳐도 휘두르기 소리는 나고, 적 수만큼 중복 재생하지 않아야 합니다. 피격·사망·해체의 예전 임시 중복 효과음은 해당 새 연결로 대체했습니다.
5. 현재 클립 샘플링은 AnimationEvent를 실행하지 않으므로 임시 자동 발소리를 유지합니다. 재생 방식과 중계를 함께 연결한 뒤 최종 발 접촉 이벤트로 옮길 때 PlayerAnimationAudio의 **임시 자동 발소리**를 끕니다. `PlayAnimationSound`의 문자열 인자에 위 호출 키를 넣습니다. 기존 자동 호출이 있는 다른 동작도 애니 이벤트로 옮길 때 한쪽만 사용합니다.
6. Run·신규 Evade·Back_Roll·두 번째 Execute는 실제 애니 선택이 정해진 뒤 해당 이벤트에서 호출합니다. 현재 새 입력·상태·선택 규칙을 추가한 것은 아닙니다.

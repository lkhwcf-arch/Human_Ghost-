# 쇄문아비 2페이즈 Attack2 확인 안내

> **아트 공동 기여:** 공급된 원본 아트의 제작·Git 외부 파일 전달에는 아트 담당자가 함께 참여했습니다. 아래 리소스 가공·프리팹·애니메이션·화면 연결 이력과 원본 제작 기여를 구분합니다. 미공급 전용 자산은 완료로 표기하지 않습니다. [작업자·커밋 기준](../개발자용%20설계문서/현재%20구현과%20검증%20현황.md#5-작업자별-역할과-git-근거)

기존 게임의 `attack2_00~12 → attack5_00~12` 순서를 기준으로 만든 2페이즈 리깅 시험 클립입니다. 승인된 Idle·Walk·Attack1과 공격 리그를 변경하지 않고 별도 클립·컨트롤러·씬을 추가했습니다. 실제 게임에는 연결하지 않았습니다.

## 실행과 편집

    A[전용 확인 씬 열기] --> B[동작 재생]
    B --> C[방향·관절·연결 확인]
    C --> D[피드백 전달]

1. `Assets/5.Animation/Swaemunabi_Phase2/Scenes/Swaemunabi_Phase2_Attack2_Study.unity`를 엽니다.
2. Play를 누르면 왼쪽 2페이즈 리그와 오른쪽 기존 1페이즈 원화 26장이 같은 시간으로 재생됩니다.
3. 좌우 각각 Attack2 네 번, 총 여덟 번을 재생합니다. 바로 연속 재진입하고 Idle·Walk·Attack1에서 들어오고 나가는 경우를 함께 확인합니다. 약 32초 후 Idle에 머뭅니다.
4. Animation 창에서 `Clips/Swaemunabi_Phase2_Attack2_Study.anim`을 선택해 몸통과 팔의 키를 편집할 수 있습니다. 길이는 1.55초입니다.

사용한 프리팹은 기존 `Prefabs/Swaemunabi_Phase2_AttackRig.prefab`입니다. 새 공격의 뼈 포즈는 .anim이 담당하며 비교 스크립트는 원화 표시·이동·반전·상태 전환을 담당합니다. 게임 전투 로직이나 기존 컨트롤러에 새 전이를 추가하지 않았습니다.

## 반드시 구분할 차이

현재 게임은 26장을 전체 1.55초에 균등 배치하지만 판정은 0.50~0.60초와 0.85~0.95초입니다. 두 번째 판정 시점의 원화는 `attack5_01~02`이며, 큰 횡 휘두르기는 그 뒤에 보입니다. 이번 클립은 **현재 게임의 원화 순서와 시간을 유지**했습니다. 판정에 맞추기 위해 원화 순서를 재배열하거나 전투 설정을 임의로 고치지 않았습니다. 이 시간 대응을 바꿀지는 팀 확인이 필요합니다.

원화의 몸통이 돌아가며 가려지는 준비 자세는 현재 2페이즈 한 장으로 완전히 재현할 수 없습니다. 오른팔을 몸 뒤에 두는 근사 자세를 사용했습니다. 원화에 들어 있는 긴 잔상과 주황색 타격 이펙트는 2페이즈 그림에 없으므로 새로 그리거나 다른 무기로 확정하지 않았습니다. 체형·옷자락·부품 겹침의 차이도 남습니다.

실제 비교 이미지는 같은 캐릭터 폴더의 `Validation/attack2_*`에 있습니다. `hit1`, `hit2_window`, `cross_body`, `late_sweep`를 함께 보면 판정과 원화 움직임의 차이를 확인할 수 있습니다. 검증 수치와 변경 범위는 [Attack2 설계와 검증](../개발자용%20설계문서/쇄문아비%202페이즈%20Attack2%20설계와%20검증.md)을 참고하세요.

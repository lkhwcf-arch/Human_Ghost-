# 1115 그림 연결 확인 안내

멈춤 메뉴의 조작 안내를 열어 오른쪽 나무 패널의 외곽이 투명하게 표시되는지 확인합니다. 패널 그림은 스크린샷을 참고해 AI로 재구성한 파생 이미지입니다. 언어와 키보드 배열을 바꿔 안내 글자가 중복 없이 갱신되고 테두리 안에 들어가는지 확인합니다.

2026-11-15 기준입니다. 상세 구현·검사 범위는 [개발자 연결과 QA](../개발자용%20설계문서/1115%20리소스%20연결과%20QA%20현황.md)를 봅니다.

## 새 피격 효과

실행 중 적을 공격하면 새 붉은 베기 그림이 나옵니다. 단발 효과는 약 0.3초 뒤 사라지고 다음 타격에서 다시 처음부터 재생됩니다. 판정·피해·히트스톱 수치는 이번 그림 교체로 바꾸지 않았습니다.

## 잔불·빙판

- 산길 8002 잔불 두 곳: 단색 사각형 대신 타는 잔해가 바닥에 붙어 표시됩니다.
- 협곡 8003 빙판 세 곳: 가운데를 반복하고 양끝 조각을 이어 너비 10/10/6칸을 덮습니다.
- 그림의 높이가 바뀌어도 판정 높이는 기존 0.2칸입니다. 잔불 피해·빙판 넉백 두 배 규칙은 유지합니다.

원본 그림은 `Assets/4.Sprite/Map/FieldObject`에 있습니다. 색은 원본대로 사용하며 불빛용 Light2D는 별도 추가하지 않았습니다.

## 옹귀는 데이터 공급 대기

대기5·걷기9·피격5·사망13프레임과 기본 자세·돌 그림을 클립으로 준비했습니다. 폴더는 `Assets/5.Animation/Characters/Onggwi`이며 각 `.anim`을 선택해 확인할 수 있습니다.

원본 Language 시트 30350의 비고는 **Monster 3005 예정, 수치 확정 후 행 추가**입니다. 3004는 기존 짐 던지는 지게귀입니다. 사용자 확정에 따라 옹귀의 코드 행·능력·보상·배치가 공급되기 전에는 3004를 바꾸거나 옹귀를 맵에 추가하지 않습니다.

기획자가 다음 내용을 공급하면 연결을 이어갈 수 있습니다.

1. Monster 3005와 UnitStat 연결, 체력·공격력·체세·이동·AI·인식 값.
2. 공격/투사체 규칙과 타이밍, 필요한 공격·처형 그림.
3. MonsterReward·ExecuteReward·MonsterAggro와 콘텐츠 사용 여부.
4. 가마터 스폰의 교체 대상·점 좌표와 최종 마릿수.

Stage 시트 비고의 옹귀4·지게귀4·허수귀1 계획과 현재 지게귀8·허수귀1 배치를 대조한 뒤 작업합니다. 새 보상이 정해지면 갈림길 혼 보상과 재입장 중복 지급도 다시 확인해야 합니다. 현재 데이터와 원본 그림은 이번에 덮어쓰지 않았습니다.

## 반영 상태

G-103~G-105 변경을 최종 QA 후 Develop에 통합하는 요청입니다. 실제 커밋·병합·CI 결과는 완료 보고서에 기록합니다. 새 실행파일은 별도 빌드해야 하며, 에디터 검사 통과가 부스 장치 수용 완료를 뜻하지 않습니다.

추가 QA에서 발견했던 기존 3004의 돌진은 G-105에서 원본 기획대로 제거했습니다. 가까이서는 내리찍기, 멀리서는 짐 투척을 유지하며 옹귀 교체와는 별개입니다.

## 새 장부방 실내

Stage 8005는 새 JangbuBangNew 배경과 책상·상자·책장을 사용합니다. 책상은 기존 장부 조사 위치에 맞췄고 출입구 쪽은 비워 두었습니다. 책상과 상자 위 촛불2개는 9프레임으로 반복됩니다. 기존 외부 건물의 불·연기는 실내에서 표시하지 않습니다.

기존 마을 문으로 들어가 책상 부근에서 F로 조사합니다. 첫 조사에서는 결박 가르기 해금 안내, 다시 조사하면 재조사 안내가 나오는 흐름을 유지합니다. 왼쪽의 돌아가기 안내로 마을에 나갔다가 재입장할 수 있습니다. 위치·충돌·진행 규칙은 이번 그림 작업에서 바꾸지 않았습니다. 실제 명부 조사와 문 왕복·재조사를 확인했습니다.

개발자 재생성 메뉴와 자세한 배치는 [새 장부방 실내 배치](../개발자용%20설계문서/1115%20리소스%20연결과%20QA%20현황.md#6-새-장부방-실내-배치-g-104)를 봅니다. 그림 원본은 보존했으며 최종 통합 범위에 함께 포함합니다.

## 턱 이동·상호작용 안내·약초 표시

공중에서 턱에 닿으면 기존처럼 자동으로 매달립니다. 올라갈 때 손을 걸고 몸을 올린 뒤 발판 위로 넘어가는 1초 흐름으로 조정했으며, 중간에 캐릭터가 커졌다 작아지거나 마지막 자세에서 떠오르는 현상을 줄였습니다. 놓으면 공중 낙하 자세부터 보이고 곧바로 같은 턱을 다시 잡지 않습니다. 가마터 실제 턱6곳에서 완료·놓기·피격 취소를 확인했습니다.

상호작용 안내는 F와 동작 문구를 더 크고 굵게 표시하고 어두운 배경판을 붙였습니다. 한국어/영어 문구 길이에 따라 배경판도 맞춰집니다. 약초 그림은 틀 안에서 3단위만 위로 올렸습니다. 실제 1080p 두 언어 화면을 확인했습니다. 다른 애니메이션은 클립 참조·키와 적 접지를 검사했으며 모든 그림의 수동 미술 검수를 대신하지는 않습니다.

## 화면·발판 인식과 이동 피드백 후속 (G-106)

일반 적은 같은 지면 구간과 실제 게임 화면 안에서 인식합니다. 위층에 아직 올라가지 않았거나 매달려 있을 때 먼저 공격하지 않으며 화면 밖/다른 구간으로 벗어나면 추적과 공격을 정리합니다. 같은 발판에서 하는 보통 점프는 추적을 유지합니다. 실제로 올라서고 기존 인식 조건을 충족하면 다시 인식합니다.

가마터 두 사다리는 그림 축에 몸을 맞췄고, 사다리 뒷모습은 올라가기 전의 좌우 방향 때문에 뒤집히지 않습니다. 밝은 양끝 가로대가 있는 활성 사다리와 얇게 윗면을 표시한 발판으로 실제 이동 경로를 구분합니다. 장식처럼 보이는 구조물은 이번에 새 길로 바꾸지 않았습니다. 아래 방향을0.5초 유지하면6칸 아래를 보고 놓으면 돌아옵니다. 위 보기는3칸을 유지합니다.

처형 F 글자는 그대로 사용하고 프리팹에 남은 E 그림 참조를 제거했습니다. 한국어/영어 각각20회 재활성화와 실제 상호작용 명령 경로를 확인했습니다. 물리 키보드 결과를 새로 확인했다고 적지는 않습니다. 상세 내용은 [화면·발판 인식과 이동 보완](../개발자용%20설계문서/1115%20화면·발판%20인식과%20이동%20피드백%20보완.md)을 봅니다.

## 새 플레이어 피격·점프 (2026-11-16)

Player_Hit_Edit의4프레임과 Player_Jump_Edit의7프레임을 연결했습니다. 점프0~4는 공중,5~6은 착지에서 쓰며 짧은 점프에서도 착지 그림이 나옵니다. 착지 표시 때문에 조작을 더 잠그지 않으며 공격으로 즉시 중단됩니다. 일반 피격과 기존 공유 Slow 표현이 새 그림을 사용하고 치명/다운의 기존 전용 표현은 유지합니다. 원본 PNG·meta와 기존 클립GUID는 보존했습니다.

재생성은 `Human Ghost > Animation > Rebuild Player Hit and Jump 1116`입니다. 실제 이동·피격·낙하·착지/공격 중단을 확인했으며 최신 실행파일 체감은 재빌드 후 확인합니다. 전체 통합 피드백과 담당별 다음 작업은 [최신 사용자 작업 목록](../개발자용%20설계문서/1115%20유저테스트%20기획%20반영%20현황과%20사용자%20작업%20목록.md)을 봅니다.

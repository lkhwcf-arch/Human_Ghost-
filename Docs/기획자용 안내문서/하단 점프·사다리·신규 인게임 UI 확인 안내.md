# 하단 점프·사다리·신규 인게임 UI 확인 안내

기준: 2026-11-09. 공급 데이터·PNG 원본은 수정하지 않았습니다.

## 하단 점프

- 일방 발판 위에서 **↓ + 현재 조작 방식의 점프 키**를 누르면 밟고 있는 발판을 통과해 아래로 내려갑니다. 패드도 아래 방향+점프입니다.
- 기획 K18 허용7종 Air_Platform_3/4/5/7/8/10/12에 적용했습니다. Map·Map_ME의 같은7종 모두 DropThroughPlatform 허용 컴포넌트를 가집니다. 일반 지면·비허용 발판은 통과하지 않습니다.
- 대화/모달 중에는 발동하지 않습니다. 통과한 발판 하나만 잠시 무시하며 다음 발판에 착지합니다. 발판 전체 충돌을 끄지 않습니다.

## 사다리

- 사용자 지정 **새 Map_ME 맵의 사다리27곳**에 연결했습니다. 사다리 가까이서 ↑로 잡고, ↑/↓를 유지하면 오르내립니다. 입력을 떼면 매달린 자세로 멈춥니다.
- 점프는 사다리에서 이탈합니다. ↓+점프는 아래로 놓고, 허용 일방 발판 위라면 그대로 내려갑니다. 상단에서는 인접한 발판을 찾아 올라섭니다.
- 피격/사망·사다리 제거·씬 종료 때 연결을 해제합니다. 사다리 밖 ↑ 상호작용과 기존 모서리 매달리기는 유지합니다.
- LadderClimbArea는 기존 트리거 영역을 사용합니다. Collider 크기·위치와 원본 스폰/테이블은 변경하지 않았습니다. 기본 확인 속도3타일/초는 컴포넌트 Inspector에서 조정합니다.
- `Player_LadderClimb.anim`은 정리한 Climb의6→7→8→9→8→7 프레임을 반복합니다. 아래로 갈 때 역방향, 정지 때 현재 프레임 유지입니다. 진입 소리는 기존 PLAYER_CLIMB/Sound3022입니다.
- 현재 실행 목록은 기존 K9 맵입니다. Map_ME의 본게임 등록/이동 데이터 공급은 별도 범위이며 이번에 실행 맵을 교체하지 않았습니다. 기능·영역은 Map_ME 프리팹에 준비되어 있습니다.

## 신규 그림 적용 프리팹

| 프리팹 | 반영 |
| --- | --- |
| PlayerHealthBar | Player_Hp의 두꺼운 붓 획, 검정 체력·회색 잔상·밝은 빈 영역 |
| HudScreen | 얇은 기력, 보스 체력/체세 붓 획, 약초 아이템 틀 |
| TextboxScreen | 새 대화창·이름판에 맞는 글자/여백 |
| InteractPrompt | 전체 E 키 그림, 중복 E 글자는 표시에서 제거 |

체력/기력/보스 막대는 Image Filled로 가로를 잘라 표시해 감소 중 그림을 찌그러뜨리지 않습니다. 체력바 크기는 공급 HealthDisplayConfig(현재240×20)를 따릅니다. 수치·색 규칙·피해 잔상·HUD 흐리기는 유지합니다. 원본에서 따로 분할된 보스 획 끝/E 조각은 추가 Sprite로 합치고 대화창은 고해상도 원본을 사용합니다.

## 확인 범위

격리한 실제 재생에서 하단 점프/착지·일반 점프·모달 및 사다리 이동/중단을 검사했습니다. UI는 실제 체력/기력 변화와 프리팹 그림 연결, 대화창/아이콘 배치를 별도로 확인했습니다. 본게임 완주·실행파일 빌드는 별도입니다. 애니메이션 파일과 순환 씬은 [캐릭터 확인 안내](캐릭터%20스프라이트%20애니메이션%20확인%20안내.md)를 따릅니다.

## 절벽 매달리기·기어오르기 — 2026-11-10

절벽을 잡으면 벽을 바라본 채 자세와 위치를 고정합니다. 좌우를 눌러도 매달린 모션이 흔들리거나 뒤집히지 않습니다. 위 또는 점프로 기어오르면 약0.68초 동안 모션과 함께 위→안쪽으로 이동합니다. 완료 전에는 일반 이동·전투가 잠기며 완료하면 눌러둔 방향으로 복귀합니다. 아래는 놓기입니다. 피격·사망으로 끊기면 현재 위치에서 떨어지고 발판 위로 순간이동하지 않습니다. 사다리의 위/아래/정지는 기존 동작을 유지합니다.

Map_ME27곳 모두 위·아래·정지 기능을 격리 확인했습니다. 사다리에서 위/아래 입력을 바꾸어도 처음 자세로 재시작하지 않습니다. 절벽 매달리기→기어오르기→대기 전환의 크기 보정과 표시 기준점 고정도 확인했습니다. 최종 체감은 실제 Play에서 확인합니다.

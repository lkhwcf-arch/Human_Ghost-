1. `Assets/5.Animation/Swaemunabi_Phase2/Scenes/Swaemunabi_Phase2_Attack1_Study.unity`를 엽니다.
2. Play를 누르면 왼쪽 2페이즈 리그와 오른쪽 기존 1페이즈 공격 원화가 같은 공격 시간으로 재생됩니다.
3. 좌우 방향에서 각각 공격 세 번, Idle → Attack1 → Idle, Attack1 → Walk → Attack1 → Walk 순서를 확인합니다. 약 25초 뒤 Idle에 머뭅니다.
4. Animation 창에서 `Clips/Swaemunabi_Phase2_Attack1_Study.anim`을 선택하면 뼈 위치·회전과 오른팔 표시 순서를 편집할 수 있습니다. 현재 승인된 Idle·Walk 클립과 리그는 바꾸지 마세요.

게임 설정의 준비 0.70초, 타격 0.12초, 회복 0.60초를 합한 1.42초를 사용합니다. 오른쪽 원화는 기존 `PreviewBossSprite`처럼 총시간에 13장을 균등 배치합니다. GIF 자체 재생 시간 1.69초와는 다릅니다.

두 그림은 같은 100 PPU와 배율 2.3, 같은 바닥선에 놓았습니다. 체형과 원래 서 있는 높이는 서로 다릅니다. Walk는 초당 2유닛으로 이동하고 공격 중 부모 위치는 유지합니다. 좌우 시험을 바꿀 때만 위치를 초기화합니다.

## 확인된 차이와 다음 작업

- 00~03번의 팔 들기, 06~08번의 앞으로 내려치기, 09~12번의 복귀 순서를 대응했습니다. 시작·끝은 기존 2페이즈 기본 포즈입니다.
- 04~05번은 원화에서 팔과 몸통의 보이는 면이 달라집니다. 2페이즈에는 해당 면의 그림이 없으므로 시험 클립의 접힌 팔 위치는 근사치입니다. 확정된 팀 원화로 취급하면 안 됩니다.
- 기존 몸통·왼팔·오른팔 8뼈 리그는 입체적인 몸통 회전, 옷자락의 새로운 실루엣, 가려진 면을 그대로 재현하지 못합니다. 오른팔·어깨 메시 뒤집힘과 도트 늘어남도 남습니다.
- 다음 기술 작업 후보는 기존 Idle·Walk를 보존한 **공격 전용 사본의 어깨·팔 메시와 가중치 개선**입니다. 그래도 보이지 않던 면이 필요한 부분은 원본 공격의 어느 모습으로 맞출지 팀 확인과 추가 그림이 필요합니다. 현재 결과에서 임의로 새 공격 디자인을 확정하지 않습니다.

실제 Play 화면은 같은 폴더 아래 `Validation/attack1_study_right_fold.png`, `attack1_study_right_strike.png`와 왼쪽 방향 대응 파일에서 볼 수 있습니다. 수치와 구현 범위는 [설계·검증 문서](../개발자용%20설계문서/쇄문아비%202페이즈%20Attack1%20대응%20시험과%20한계.md)에 있습니다. 비교용 원화는 분석 기준이며 완성된 2페이즈 공격을 원화 교체 방식으로 대체한 것이 아닙니다.

기존 게임 씬, 보스 전투 코드, 피해 판정, 이동 로직에는 연결하지 않았습니다. Play가 막히면 Console의 오류를 먼저 확인하세요. 이 시험본은 성능 최적화·출시 품질 검증을 완료한 자산이 아닙니다.

# 정수 단위 설정과 확인 안내

2026-11-15. 프로젝트의 정수화 기본 원칙에 따라 초·타일 실수 설정과 내부 타이머를 정수 단위로 맞췄습니다. 설계·공통 계약·검사 범위는 [개발자 설계](../개발자용%20설계문서/정수%20단위%20감사와%20시간·좌표%20경계%20설계.md)를 따릅니다.

## 1. 입력할 단위

| Inspector 항목 | 현재 공급값 | 뜻 |
| --- | --- | --- |
| 카메라 따라가기 시간 | 120ms | 기존0.12초 |
| 위아래 보기 대기 | 500ms | 위/아래를 반초 유지 |
| 위아래 보기 거리 | 300 tile_x100 | 위/아래3타일 |
| 임시 점프 시간 | 800ms | 기존0.8초 |
| 임시 해체 거리 | 175 tile_x100 | 기존1.75타일 |
| 사다리 속도 | 300 tile_x100/초 | 기존3타일/초 |
| 보스 리그 대기·걷기 비율 | 8000 / 10000 | 기존0.8배 |
| 지게귀 돌진 재생 비율 | 14000 / 10000 | 기존1.4배 |

이 값은 새 기획 수치가 아니라 기존 공급값의 단위 변환입니다. 타일당 화면 거리·Transform·색상 등 Unity 표시 입력은 실수일 수 있습니다. 화면 좌표를 규칙 수치 대신 시트에 넣지 않습니다.

## 2. 설정 변경 순서

```mermaid
flowchart LR
    A[해당 기능 Inspector 단위 확인] --> B[정수 값 수정]
    B --> C[씬·프리팹 저장]
    C --> D[프로젝트 검사·개발자 검증]
    D --> E[새 실행파일 빌드·화면 확인]
```

기존18개 씬/프리팹은 개발자가 같은 의미의 값으로 변환했습니다. 이전 초 필드에0.5를 다시 넣거나 파일 이름만 예전 것으로 되돌리지 않습니다. 설정 복사 때 새 필드 이름과 ms/tile_x100/분모10000 단위를 확인합니다. 시트 스키마는 바뀌지 않았고 원본 배포값을 임의로 바꿀 필요도 없습니다.

## 3. 실제 화면 확인

1. 새 빌드에서 도화골 바닥에 서서 A 방식 ↑/↓, B 방식 W/S를 각각 500ms 이상 유지합니다. 위/아래3타일 보기와 키 해제 후 복귀를 확인합니다.
2. 공중·대화/메뉴 잠금·장부방에서는 상하 보기가 나오지 않아야 합니다. 현재 보스방은 추적 카메라를 사용하므로 보스방 전체가 비활성인 것은 아닙니다.
3. 사다리·점프·해체·서낭당 일어서기·사망 복귀·엔딩 대기 시간이 이전 체감과 같은지 확인합니다.
4. UI 잔상·알림·발소리·리그 재생 속도를 확인하고 멈춤/해제 뒤 시간이 빨라지거나 누락되지 않는지 봅니다.

합성 입력·정수 좌표 자동 검사 통과와 실제 화면 수용은 구분합니다. 이번 변경 이전에 만든 실행파일은 정수화 수정이 반영되지 않습니다.

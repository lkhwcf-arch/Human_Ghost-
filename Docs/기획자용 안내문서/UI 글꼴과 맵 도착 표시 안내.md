## 확인 순서

1. Play에서 ESC와 옵션을 열어 글꼴·조작·적용/취소를 확인합니다. 대사와 스킵/상호작용 안내도 확인합니다.
2. 미해금 스킬명은 숨깁니다. 결박 가르기를 해금하면 기존 아이콘 오른쪽 위에 표의 스킬명이 나타나며, 해금 알림에도 2번을 사용합니다.
3. 맵 준비·복원과 로딩 종료 후 중앙 이름이 0.5초 등장 → 2초 유지 → 0.5초 퇴장합니다. 입력을 막지 않으며 일시정지와 무관한 실시간 표시입니다. 재진입하면 다시 표시합니다.
4. 맵 이름은 Stage.TextID → Language.KO를 사용합니다. 현재 표의 8004 이름은 ‘관문’입니다. 문구 변경은 데이터 담당에게 요청합니다.
5. 하단 약초·스킬 카드가 기존의 150%인지 확인합니다. 키/수량·쿨타임도 함께 확대했고, 카드 사이와 화면 가장자리 여백을 조정했습니다. 기존 Q/I·Z/U 표시와 약초 수량은 그대로입니다.

## 수정 위치

- 공용 글자: Assets/2.Model/Prefabs/UI의 각 Text.font.
- 스킬명: HudScreen.prefab의 SkillArtwork/SkillName. 부모 카드 배율을 상속합니다.
- 맵 이름: TextboxScreen.prefab의 StageNameBanner. 글자 크기·위치와 Fade In/Hold/Fade Out을 조절합니다.
- 하단 카드: HudScreen.prefab의 HerbItemFrame·SkillArtwork. 현재 localScale X/Y=1.5입니다.

Unity Edit 격리에서 글꼴 150개·현재 한글 표의 글자 지원·맵명 5종·페이드·1920×1080/1280×720 배치 255항목, 실제 해금 전후 표시 3항목을 확인했습니다. 옵션 기존 60항목도 재통과했습니다. 전체 Play 조작·실제 씬 왕복·게임 빌드는 별도입니다. [연결 설계](../개발자용%20설계문서/UI%20글꼴과%20맵%20도착%20표시%20설계.md)

## 상호작용·키판·체력바 보완 — 2026-11-13

- E와 설명이 대상 위의 한 묶음으로 나옵니다. E 크기를 줄이고 위치를 조금 내려 게임 속 대상에 가깝게 맞췄습니다. 문구 길이가 바뀌어도 키 간격과 묶음 중심을 유지합니다. 이동·범위 이탈·매달리기/처형의 E 단독·장부 조사 그림도 확인합니다.
- 약초Q/I·스킬U는 키판 안에 중앙 정렬하고 굵기/크기를 보정했습니다. 실제 수량도 숫자 배경 중앙에 표시합니다. 기본 UI 글꼴은 유지합니다.
- 체력 막대와 장식 배율을 통일해 다른 화면 비율에서도 전체 획이 맞습니다. 목표 안내는 체력바/ESC와 겹치지 않게 우측 상단으로 옮겼습니다. HUD 평상시 불투명도는90%로 높이고 강조100%를 유지합니다.

# 패링과 전투 보완 확인 안내

2026-11-10 적용. 모듈 책임과 담당 경계는 [설계](../개발자용%20설계문서/패링과%20전투%20보완%20모듈%20설계.md)를 참고합니다.

## 조작

| 설정 | 패링 | 기존 구르기 |
| --- | --- | --- |
| A: 방향키 | 왼쪽 Shift | Space |
| B: WASD | 오른쪽 Shift | L |
| 패드 | LT | B |

누를 때 기력30을 쓰고 0.3초 동안 정면 공격을 막습니다. 성공 뒤 0.2초 굳으며 실패하면 누른 뒤 총0.5초 후 풀립니다. 일반몹은1초 스턴, 보스는 체세30 감소입니다. 잡기와 사슬은 막지 않습니다. 기력이 모자라면 동작 없이 게이지만 깜빡입니다.

공중·매달리기·약초·피격 경직 중에는 쓸 수 없습니다. 평타1~3타의 다음 공격 입력 구간에서는 패링으로 취소할 수 있습니다. 전용 패링 그림 전까지 평타 첫 프레임을 임시 자세로 사용합니다.

## 다음 Play 확인 순서

1. A/B 설정을 바꾸며 지정한 Shift만 패링이 되는지 확인합니다. 누른 채 반복 소모되지 않는지, 일시정지·오류창에서 작동하지 않는지도 확인합니다.
2. 일반 공격을 정면에서 막고 피해0·스턴·불꽃·쇳소리를 확인합니다. 후방, 판정 만료 뒤, 기력 부족도 확인합니다.
3. 돌진 정지·투척 소멸, 잡기/사슬의 패링 불가, 보스의 HP 무피해·체세 감소를 확인합니다.
4. 투척이 공중 발판을 통과하고 땅에서 사라지는지, 사망 모션이 끝난 적이1초 동안 흐려지는지 확인합니다.
5. 낙사 즉사, 1~3타330ms/4타550ms를 확인합니다. 창모드 변경은 담당 범위 밖으로 제외했습니다.

현재 코어753·데이터993 및 Unity 프리팹 연결/입력 처리19건 통과입니다. 위 실제 Play·청취·실행파일 확인은 아직 완료로 집계하지 않습니다.

보상·재화·강화·서낭당·관문·갈림길·무기 스탯 합산·상태 등록은 별도 담당 범위입니다. 해당 기능의 기존 구현은 유지하며 이번 새 연결은 제거했습니다. 어두도 구현은 보류입니다.

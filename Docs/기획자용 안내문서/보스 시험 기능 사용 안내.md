# 보스 시험 기능 사용 안내

기준일: 2026-11-13. 에디터·development 테스트 빌드의 게임 맵에서 사용하는 확인 도구입니다. 정식 release에는 조작 코드가 포함되지 않습니다.

## 1. 왜 사용하는가

보스를 매번 처음부터 찾아가 싸우지 않고 특정 패턴·체세 붕괴·처치 후 흐름을 확인하기 위한 도구입니다. 실제 보스의 공개 요청을 사용하므로 패링·공격 판정·엔딩 코드를 다른 시험용 구현으로 바꾸지 않습니다.

```mermaid
flowchart LR
    A[테스트 빌드에서 게임 맵 진입] --> B[F8 시험창]
    B --> C[보스방 이동]
    C --> D[패턴·체세·처치 요청]
    D --> E[실제 게임 결과 확인]
```

## 2. 조작 순서

1. 에디터에서 게임을 실행하거나 GitHub의 development 빌드를 받습니다. 타이틀이 아닌 게임 맵에 들어갑니다.
2. 데이터 로딩·대화·저장·일시정지가 끝난 뒤 **F8**을 누릅니다. 마우스로 시험창을 조작합니다. F8을 다시 누르면 닫습니다.
3. ‘보스방으로 바로 이동’을 누릅니다. 이미 보스를 처치한 진행이면 새 게임을 시작해야 합니다.
4. 보스 진입 대사가 있다면 기존 진행 입력 또는 Enter로 마친 뒤 F8을 엽니다.
5. 확인할 패턴이나 ‘보스 처치’를 선택합니다. 창은 게임을 자동으로 정지시키지 않으므로 전투 중 피해를 받을 수 있습니다.

## 3. 버튼별 역할

| 버튼 | 동작 |
| --- | --- |
| 보스방으로 바로 이동 | 기존 맵 이동 경로로 보스방 진입. 처치 기록을 임의 삭제하지 않음 |
| 보스 처치 | 현재 체력만큼 피해를 요청해 실제 사망·후속 흐름 실행 |
| 체세 붕괴 | 현재 체세만큼 피해를 요청해 노출·해체 확인 |
| 패턴 자동 선택 | 1·2페이즈 자동 선택·추적 켜기/끄기. 진행 중 패턴 정리 |
| 패턴 번호 실행 | 등록된 실제 패턴을 선택해 실행하고 자동 선택은 끔 |

패턴 목록은 런타임에 등록된 개수·종류를 사용합니다. 노출·무적·해체·사망 상태에서는 정상 규칙에 따라 요청이 거부될 수 있습니다. 강제로 상태를 덮어쓰는 기능이 아닙니다. 다시 자동 전투를 보려면 자동 선택을 켭니다.

## 4. 엔딩과 확인할 내용

보스 처치 → 해체 종료 대기 → 데이터에 있는 처치 대화 → Ending.mp4 → 완주 또는 Enter 스킵 → 맵 탐색 → 오른쪽 끝 이동 시도 → 감사·마무리 안내 → 타이틀 암전을 확인합니다. [엔딩 상세 확인](기획자용%20컷씬%20표시와%20씬%20이동%20안내.md#현재-엔딩을-연결하려면)을 함께 봅니다.

## 5. 주의사항

- 테스트 빌드에서만 사용합니다. release에서 F8 화면이 나타나면 배포 종류를 확인합니다.
- 시험 처치도 실제 임시 진행·통계에 반영될 수 있고, 이후 저장하면 기록에 남을 수 있습니다. 배포 검증용 별도 새 게임으로 확인합니다.
- 보스 부활·저장 삭제·패링 내부 변경은 하지 않습니다. 반복 처치 시험은 새 게임에서 진행합니다.
- 로딩·사망·저장·대화·모달 중에는 실행을 막습니다. 요청이 거부되면 해당 상태를 먼저 마칩니다.
- 실제 게임 빌드와 영상 디코딩·관문 충돌·화면 배치는 자동 코드 검사를 대신할 수 없으므로 실행해서 확인합니다.

## F8 입력 연결 보완 — 2026-11-14

F8 처리 메서드의 호출이 빠져 시험창이 열리지 않던 부분을 연결했습니다. 비활성화 시 시험창과 커서 상태도 정리합니다. 보스방 이동은 StageExit 데이터의 도착 앵커를 사용합니다. 별도 Inspector 필드 할당은 필요하지 않습니다.

코드 반영 후 Play를 다시 시작하고 Game 화면을 한 번 클릭해 키 입력을 받을 상태로 만든 뒤 F8을 누릅니다. 시험창에서 보스방 이동 후 대화를 마치고 다시 F8을 열어 처치를 요청합니다. 정식 release에서는 시험 코드가 제외됩니다. 여러 도착 앵커가 있어 직접 이동 목적지를 결정할 수 없으면 시험창 상태와 오류 로그를 확인합니다.

### 시험창 크기와 조작

시험창의 글자·버튼을 확대하고 화면 높이에 비례해 크기를 조절하도록 보완했습니다. 패턴 목록이 길면 창 안에서 스크롤합니다. 제목 부분을 끌어 위치를 바꿀 수 있고 화면 크기가 바뀌면 창 위치를 화면 안으로 보정합니다. F8 열기·닫기와 시험 기능은 같습니다.

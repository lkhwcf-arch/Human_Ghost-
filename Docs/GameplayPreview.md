# 임시 게임플레이 육안 확인

## 실행

Unity에서 `Assets/1.Scene/GameplayPreview.unity`를 열고 Play를 누른 뒤 Game 뷰를 클릭합니다. 장면에는 기존 PlayerGameplay·BossGameplay와 허수귀 HusugwiGameplay·지게귀 JigegwiGameplay 프리팹 인스턴스가 있습니다. 청록색은 플레이어, 빨간색은 보스, 초록색은 허수귀, 주황색은 지게귀입니다. 플레이어·보스·일반몹에 현재 상태·체력(·자원)을 표시합니다. 일반몹은 플레이어를 발견하면 추적·공격합니다. 일반몹 사각형이 밝은 빨간색이면 공격 판정 중, 보라색이면 지게귀 벽 충돌 허점입니다. 허수귀에게 잡히면 플레이어 이름표에 남은 공격 연타 횟수가 나옵니다(X/X 연타로 해제).

제공 GameDataAssets → GameDataInitializer → 기존 PlayerRuntime/BossRuntime 순으로 실제 배포 데이터를 소비합니다. CSV 파서·조회 저장소·Bootstrapper를 추가하지 않습니다. 이 장면의 초기 자원은 Preview 컴포넌트의 시작 시 스태미나 최대로로 명시하며, 끄면 시작 스태미나를 사용합니다. 운영 스폰 정책을 확정한 값은 아닙니다.

씬의 제목·조작 안내·상태·체력/스태미나/체세·Hierarchy 이름과 확인용 Inspector 표시를 한글로 제공합니다. 프로젝트의 기존 Pretendard-Regular 글꼴을 재사용합니다. 코드 식별자와 프리팹 파일명은 유지합니다.

## 조작

게임패드 작업은 보류하며 현재 확인 범위는 키보드 조작입니다.

| 입력 | 육안 확인 |
| --- | --- |
| 방향키 | 사각형 이동, 대기/이동 전환 |
| C | 점프 요청, 공중 재점프 거부, 착지 |
| X | 기존 지상 3타·공중 1타, 공격 중 자원 소모 |
| Space | 구르기 요청·거리·자원·무적 색상 |
| 보스 가까이에서 공격 | 노란 판정 사각형이 겹치면 기존 보스 피해·체세 API 호출 |
| H (확인 전용) | 보스 ATK/플레이어 DEF를 기존 피해 공식에 넣어 피격 요청 |
| E (확인 전용) | 가까운 급소 노출 보스에 기존 해체 시작 API 호출 |
| R (확인 전용) | 기존 해체 완료 API 호출. 체세 회복 여부는 Preview 설정에 명시 |

무적은 노란색, 공격 판정 중에는 주황색, 보스 노출은 보라색, 사망은 회색으로 표시합니다. HP/자원 값은 기존 런타임의 현재 값을 읽습니다. 다시 시작하려면 Play를 종료하고 재진입합니다.

## 임시 연결의 경계

- GameplayPreview 컴포넌트는 이 장면에만 있습니다. 프리팹 루트의 기존 런타임·입력 참조와 GUID를 유지했습니다.
- 기존 두 프리팹에 임시 시각화/사각형와 임시 시각화/이름표만 추가했습니다. 임시 시각화 그룹을 비활성화하거나 삭제하면 임시 사각형·이름표를 한꺼번에 제거할 수 있습니다.
- 이동은 수신한 tile_x100 값을 타일당 화면 거리로 변환해 Transform을 표시합니다. 점프는 제공 JumpHeight와 임시 임시 점프 시간 (초)의 포물선입니다. 바닥·벽 충돌, Rigidbody·중력·경사·모서리/매달리기·정식 카메라는 구현하지 않습니다.
- 구르기 거리·시간은 제공 Player 값을 사용합니다. 화면 이동 한계 (좌우)는 화면 밖으로 나가지 않기 위한 이 확인 장면의 표시 제한입니다.
- 공격은 노란 SpriteRenderer의 bounds와 보스 사각형 bounds가 겹치는지만 보는 임시 범위 판정입니다. 회피·치명은 재현 가능한 확인을 위해 false로 공급합니다. 운영 히트박스·대상 선택·난수 정책을 대체하지 않습니다.
- E의 범위는 Preview의 임시 해체 거리 (타일), R의 체세 복구는 해체 확인 후 체세 회복에서 조정합니다. 연출 완료 신호와 운영 종료/페이즈 정책은 여전히 별도 결정입니다.
- 애니메이션·아트·정식 HUD 레이아웃은 이 장면에 포함하지 않습니다. 일반 몬스터 체세/해체는 활성화하지 않습니다. 허수귀·지게귀 AI는 MonsterActor가 실행합니다. 이 장면의 몬스터 이동(Transform)·중심 거리 관측·화면 좌우 한계를 벽으로 쓰는 판정은 확인용이며(근접·잡기는 사각형 높이가 겹칠 때만 명중, 점프로 피할 수 있음) 운영 물리·히트박스가 아닙니다. 몬스터 데이터 ID/표시 이름과 임시 시각화 자식은 각 프리팹에서 조정합니다.

## 확인 결과

실제 Unity Play에서 가상 키보드 → 기존 Input Actions → 런타임 Update → Preview LateUpdate 경로로 16개 항목을 확인했습니다. 이동/정지·점프/착지·구르기/거리·판정 창 1회 피해·지상 3타·피격·보스 노출/해체·명시적 완료·비활성화/재활성화·텍스트 값이 통과했습니다. 가상 장치와 검사 이벤트는 종료 후 제거했습니다. 실제 키보드 사용자 조작과 운영 물리는 별도 확인 대상입니다. 게임패드 개발·검증은 보류합니다.

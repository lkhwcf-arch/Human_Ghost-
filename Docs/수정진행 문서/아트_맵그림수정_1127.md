# 아트 전달: 맵 그림 수정 목록 (11/27)

11/27 김현호가 게임을 돌며 찍은 사진으로 맵 5개(도화골·산길·가마터·갈림길·협곡)에서 어긋난 곳을 모았습니다. 기준은 11/25에 맵 꾸밈 기준으로 정한 **맵 그림 규칙 R1~R6**입니다. 사진은 `../사진/` 폴더에 번호 그대로 있습니다. 자리(x)는 맵 왼쪽 끝에서 센 칸 수입니다.

| 규칙 | 내용 |
|---|---|
| R2 올라설 수 있는 면 | 밟는 발판 윗면 = 밝은 윗선 + 일정 두께. 배경 지붕·들보엔 윗선 없이 한 단계 어둡게 |
| R3 접지 | 구조물은 땅·벽에 닿는 받침이 보이게. 사다리는 위·아래 끝이 발판에 닿게 |
| R4 중경 이음새 | 중경은 가로 반복이나 맵 길이만큼, 끊기는 곳은 안개·실루엣·큰 소품으로 가림 |
| R5 깊이 4층 | 전경 / 플레이 층 / 중경 / 원경, 한 물건은 한 층에만 |
| R6 벼랑 옆면 | 땅 테두리를 벼랑 옆면·구덩이 가장자리에도, 구덩이 아래는 짙은 어둠 |

## 1. 여러 맵에 공통 (한 번에 고치기)

### 1-1 구덩이 3종 (산길 x80~87 · 가마터 x30·x68·x104 · 협곡 x76~83)
구덩이 안이 땅 속과 같은 색이라 '떨어지면 끝'으로 안 읽힘. 협곡이 가장 심함(어두운 평지처럼 보임).
- 윗부분 1~2칸은 뒤 배경이 그대로 보이게 비우고, 아래로 갈수록 짙은 검정 + 아래에서 올라오는 안개
- 벼랑 끝 테두리(협곡은 눈 처마·고드름·부서진 얼음 조각)
- 가운데 디딤돌·A자 발판은 받침이 보이게(바닥에서 솟은 돌기둥, 바위에 박힌 다리 끝)

### 1-2 벼랑·턱 옆면 (R6)
도화골 시작 왼쪽 벼랑, 가마터 오른쪽 벼랑·언덕, 협곡 턱이 테두리 없는 검은 사각 덩어리. 맵별 땅 테두리(11/23)를 옆면에도 씀. 산길 구덩이 오른쪽 벼랑(비탈+테두리)이 기준 예시.

![](../사진/D1_도화골_시작.png)

### 1-3 기둥을 세로로 늘린 문틀 발판 (가마터)
기둥 아래쪽을 세로로만 늘려 나뭇결이 줄무늬로 번짐. 같은 그림을 자리마다 늘려 쓴 것으로 보임 → **그림을 늘리지 말고 기둥 가운데 조각을 반복**(Sprite Draw Mode Tiled/9-slice)하거나 길이별 그림을 따로 그림.

### 1-4 받침 없는 구조물 (R3)
- 가마터 큰 나무틀 발판: 오른쪽 기둥이 까치발 아래 공중에서 끝남, 사선 들보가 짧은 말뚝에서 끝남(왼쪽 기둥·사다리는 **기준 예시**)
- 산길 두 번째 잔불 위 다리(발판 14): 다리 기둥이 바닥까지 안 내려가고 사다리가 기둥 노릇 → 땅까지 닿는 나무 기둥 + 돌받침을 따로
- 갈림길 시작 흔들다리: 다리와 기둥이 매단 줄 없이 떠 있음 → 양끝을 벼랑에 묶은 밧줄·말뚝
- 산길 첫 잔불 위 T자 발판은 기둥이 땅에 잘 박혀 **기준 예시**

## 2. 가마터 중경 (R4) — 한 장으로 다시 잇기
가마터 중경이 세 번 이상 세로 직선으로 끊기고(뒤 원경이 그대로 보임), 소나무가 실루엣처럼 한 덩어리로 어둡고, 가장자리가 계단 모양으로 깨지고, 회색 사각 얼룩·세로 줄무늬가 있음.
- 중경을 가로 반복 그림으로 바꾸거나 폭을 (맵 폭 × 중경 시차 비율 + 화면 폭) 이상으로
- 중경만 한 단계 밝게·푸른 안개색 쪽으로(먼 거리감), 픽셀 크기를 다른 그림과 맞춤
- 계단 깨짐은 Import 설정 문제일 수 있어 개발·프리팹 쪽에서 먼저 확인(설정 문제면 다시 안 그려도 됨)

## 3. 위험 지형 그림

### 3-1 잔불 (산길 x23~25 · x96~98, 지스타 피드백 '용암')
눈 위에 얇게 깔린 주황 줄이라 바닥 무늬로 읽힘. 11/14 결정('Y축으로 튀지 않게', 납작한 잔해 D안)은 지키고: 숯불 밝기·대비를 올리고, 위로 날리는 불티, 주변 땅·캐릭터를 물들이는 주황 빛, 위로 오르는 연기.

![](../사진/B2_산길_두번째잔불.png)

### 3-2 빙판 (협곡, 11/14 B안)
얇은 하늘색 띠를 붙인 것처럼 보임(같은 무늬 반복, 양끝 직선, 땅 위에 얹힘).
- 얼음이 땅 윗선을 대신하게(눈 띠를 덮고 살짝 묻힘), 금·기포·눈 얼룩으로 반복 깨기, 양끝은 녹아 끝나는 조각
- 색은 밤 화면에 맞게 조금 낮추고, 천천히 지나가는 반짝임 + 가장자리 흰 선으로 시인성

![](../사진/H4b_협곡_빙판.png)

## 4. 건물·오브젝트

### 4-1 장부방 집 크기: 밖 vs 안 (새 규칙 R7 제안, 결정 대기)
밖에서 문 높이 ≈ 사람 키 0.9배, 장부방 안에서 창살 문 ≈ 사람 키 2.3배. 11/23 '집 크기 키움'대로 밖을 키우고 안은 줄여 **문 높이 = 사람 키 약 1.3배**로 맞춤.

![](../사진/D4_장부방_밖.png)
![](../사진/D6_장부방_안.png)

### 4-2 서낭당 신목 (협곡 끝, 갈림길도 같은 그림이면 같이)
눈 오는 맵인데 가지·돌무더기에 눈이 없음, 천 색 채도 높음, 픽셀이 더 굵고 평평함, 밑동이 땅에 얹힘 → 눈 쌓기, 톤 맞추기, 픽셀 크기 맞추기, 밑동을 눈 띠로 덮기.

![](../사진/H6_협곡끝_서낭당_관문.png)

### 4-3 협곡 끝 → 보스 관문 예고
협곡 끝이 다음 들판처럼 보이는데 들어가면 보스 관문. 마지막 몇 칸에 길이 좁아짐·관문 기둥·쇄문아비 사슬·붉은 부적 등으로 '관문 앞'을 그림으로 예고.

### 4-4 갈림길 폐광 입구 (K7, 11/27 결정: '여기가 위험하다' 경고)
지금은 막는 보이지 않는 벽 위에 캐릭터가 허공에 서 있음. 프리팹에서 구멍을 약 2칸으로 좁힌 뒤, 그 자리에 **위험 경고 그림**(무너진 갱구 가장자리·부러진 버팀목·경고 표식 등, 금줄은 리젠 잠금 장치와 헷갈려 피함). 사다리는 길로 남김.

![](../사진/L7_갈림길_폐광입구_허공서기.png)

### 4-5 산길 장식 사다리
두 번째 잔불 위 다리의 오른쪽 사다리는 오를 수 없는 장식으로 보임 → 빼거나 부서진 그림으로.

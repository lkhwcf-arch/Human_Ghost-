산길·협곡에서 세 번 확인. 막대가 바위·발판뿐 아니라 **뒤 배경(중경)**에도 가려짐 → 막대가 맵 그림 대부분보다 아래 순서로 그려지는 것으로 보임.

## 2. 잔불 그림 높이 0.2칸 고정 (시인성)
지스타 피드백 '용암이 안 보인다' = 산길 잔불 두 곳. 지금 잔불 그림이 높이 0.2칸으로 고정돼 얇은 줄로 보임. 아트가 불티·빛·연기를 더할 수 있게 그림 높이(또는 추가 효과 층)를 정할 수 있게 해 주세요. 판정 상자는 지금 그대로(발 판정 요청은 hazard-collider-1126 문서).

## 3. 사다리 끝에서 발판으로 옮기는 처리 (확인만)
사다리가 발판 바깥에 있으면 다 오른 뒤 캐릭터가 옆으로 순간이동해 발판에 올라섬. 사다리 자리를 고치면(프리팹 목록 P5~P7) 해결되므로 코드는 그대로 둬도 됨. 혹시 옆으로 옮기는 거리를 제한할 수 있으면(예: 0.5칸 이상이면 안 옮김) 배치 실수를 빨리 찾는 데 도움.

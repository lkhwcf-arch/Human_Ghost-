## 1. 사망 화면

### 1.1 바뀌는 것

| 지금(O09_R3·K16add_R11) | 바뀜 |
| --- | --- |
| HP 0 → 먹색 암전 1.5초 → 재시작 | HP 0 → **약 3.4초** 흐름(아무 키로 1.6초부터 넘기기) |
| 사망 문구 없음[제안이었음] | **붓글씨 한 줄** 문구(영어 "YOU DIED"식 큰 글자는 안 씀) |
| 재화 50% 잃는 걸 안 보여 줌(유저테스트 I12) | **잃은 혼·엽전을 숫자로** 보여 줌 (UX 원칙 7 "죽음은 내 탓으로 느껴진다") |
| O09 "사망 페널티·재화 드롭 없음" 줄 | 옛 문장. K16add(재화 50% 잃음, 되찾기 없음)가 맞음 → O09 고침 |

다시 서는 곳·HP 가득·약초 3·재화 50%·리스폰 규칙은 **바꾸지 않습니다**(K16add 그대로, 11/26 리젠 결정 포함).

### 1.2 흐름

| 시간 | 단계 | 화면 | 소리 | 겹 |
| --- | --- | --- | --- | --- |
| 0 ~ 600ms | **HP 0** | 조작 잠금·무적. 시간 0.3배로 느려짐. 화면 가장자리 붉은 비네트가 0 → 75%로 차오름. Dead 애니 재생 | 숨 끊김(낮은 숨 + 징 한 번) | 효과·소리 |
| 600 ~ 1100ms | **먹 번짐 암전** | 화면 가장자리에서 먹이 번져 들어와 가운데까지 덮음(먹 번짐 마스크로 디졸브). HUD 숨김. 시간은 1배로 돌아옴 | — | 효과 |
| 1100 ~ 2900ms | **문구 + 잃은 재화** | 먹색 화면 가운데: 문구 300ms 떠오름 → 그 아래 혼·엽전 줄이 나오고 숫자가 **원래 값 → 남은 값**으로 600ms 동안 줄어듦, 옆에 붉은 "−잃은 양". 그 아래 작은 글씨 "지닌 혼과 엽전의 절반을 잃었다". 오른쪽 아래 "아무 키 바로 일어서기" | 숫자 줄어들 때 엽전 흩어지는 소리 | UI 애니·소리 |
| 2900 ~ 3400ms | **밝아짐** | 죽은 맵 입구(보스방이면 서낭당 앞)에서 먹이 걷힘. HP 가득·약초 3. HUD 재화 숫자 **붉은색으로 1초** 뒤 원래 색 | — | UI 애니 |

- **아무 키 넘기기**: 1600ms(문구가 다 뜬 뒤)부터 아무 키를 누르면 바로 4단계(밝아짐)로 갑니다. 그 전 입력은 버림. [제안] 부스 관람객이 지치지 않게(O09 목적).
- 같은 맵이면 로딩 없이 3단계 화면 뒤에서 위치만 옮깁니다. 다른 맵(보스방 → 서낭당 앞이 다른 맵일 때)이면 3단계 뒤 로딩(O07) → 4단계. [제안]
- **11/26 리젠**: 사망하면 맵 몬스터가 다시 채워집니다. 채우는 작업은 3단계(먹색 화면) 동안 끝냅니다. 금줄 매듭이 죽어도 남는지(Q5)는 아직 결정 전이라 이 화면에는 표시하지 않습니다.

### 1.3 화면 구성 (`01_사망화면_시안.jpg`)

| 요소 | 내용 | 모양 |
| --- | --- | --- |
| 배경 | 먹색(#070506 근처) 위에 가장자리 쪽이 더 짙은 먹 번짐. 뒤 게임 화면은 안 보임 | 먹 번짐 마스크 재사용 |
| 문구 | 가운데 위, "숨이 끊어졌다" | 붓글씨 계열 글꼴(지금 쓰는 제목 글꼴), 약 120px(1080 기준), 밝은 한지색, 아래 붉은 붓 획 |
| 재화 줄 | 문구 아래, 혼·엽전 나란히. 아이콘 + 이름 + ~~원래~~ → **남은** + 붉은 −잃은 | 아이콘은 서낭당 UI의 혼·엽전 아이콘(ShrineUI_Icon_Hon/Yeopjeon, Currency.NoticeIcon SOUL·COIN) |
| 설명 | 재화 줄 아래 작게 "지닌 혼과 엽전의 절반을 잃었다" | 회색, 약 30px |
| 넘기기 안내 | 오른쪽 아래 "[아무 키] 바로 일어서기" | 흐린 회색, 1600ms부터 보임 |

- 잃은 양 계산은 지금 규칙 그대로(DeathLossRate 5000 = 50%, 잃는 양 내림). 예: 혼 118 → 59(−59), 엽전 37 → 19(−18).
- **잃은 게 0**(가진 재화가 0이나 1)이면 그 재화 줄은 안 띄움. 둘 다 0이면 재화 줄·설명 줄 모두 빼고 문구만.
- 에러 팝업 틀(종이 판)은 쓰지 않습니다. 사망은 창이 아니라 화면 전환이라 전체 화면 먹색이 맞습니다. (11/25 재정리의 "에러 팝업 틀 재사용" 추천은 이 안으로 바꿈)

### 1.6 완료 기준

- ☐ HP 0 → 약 3.4초 뒤 죽은 맵 입구에서 섬, 1.6초 뒤 아무 키로 넘길 수 있음
- ☐ 먹색 화면에 문구와 혼·엽전 "원래 → 남은 −잃은"이 보이고, 숫자가 줄어드는 게 보임
- ☐ 다시 선 뒤 HUD 재화 숫자가 1초 붉게 보임
- ☐ 낙사는 붉은 단계 없이 바로 먹 번짐
- ☐ 잃은 게 0이면 재화 줄이 안 보임

## 2. 혼·엽전 획득 연출 (자동 루팅)

### 2.1 원칙

- **지급은 처치 순간**(지금 MonsterReward 그대로). 알갱이는 보여 주기만 하는 꾸밈입니다. 알갱이가 날아오는 도중 죽거나 맵을 나가도 재화는 이미 들어와 있습니다(사망 계산·저장이 꼬이지 않게).
- 줍는 키 없음, 거리 제한 없음. 플레이어가 움직여도 알갱이가 따라옵니다.
- 알갱이 목적지 = **막손 몸**(가슴 높이). HUD까지 날리지 않습니다. [제안] HUD는 화면 왼쪽 위라 전투 중 시선을 끌고, 화면을 가로지르는 알갱이가 패링 예고 번쩍임을 가릴 수 있어서입니다.
- 연출 실패는 에러 A단계(30333 화면 연출)와 같게: 재화는 들어오고 알갱이만 빠짐.

### 2.2 흐름 (`03_혼엽전_획득_흐름.jpg`)

| 시간 | 단계 | 내용 |
| --- | --- | --- |
| 0 ~ 250ms | **터짐** | 몬스터 몸 가운데에서 알갱이가 위·옆으로 튐(위쪽 반원 안 무작위 방향, 속도 줄어들며). 혼은 푸른 흰 불씨, 엽전은 작은 엽전 |
| 250 ~ 400ms | **잠깐 멈춤** | 혼은 일렁이고 엽전은 돌며 반짝. 무엇을 얻었는지 보이는 시간 |
| 400 ~ 900ms | **빨려 듦** | 막손 가슴 쪽으로 곡선(2차 베지어, 위로 볼록), 점점 빨라짐(ease-in). 꼬리(Trail) 짧게. 알갱이마다 30~60ms씩 늦게 출발해 줄지어 들어옴 |
| 닿을 때마다 | **도착** | 막손 몸에 작은 반짝(4프레임) + 획득 소리. HUD 해당 아이콘이 1.0 → 1.25 → 1.0(150ms) 튀고, 숫자는 첫 알갱이가 닿을 때부터 300ms 동안 올라감. 숫자 옆 "+양"이 0.8초 떠 있다 사라짐. 혼은 푸른빛, 엽전은 금빛 |

- 처음 얻는 재화면 마지막 알갱이가 닿은 뒤 첫 획득 안내(30364·30365, 지금 있는 것)를 띄웁니다.
- 갈림길 보상 같은 큰 보상도 같은 연출, 알갱이 수만 상한까지.

### 2.3 알갱이 수 [제안]

| 재화 | 얻은 양 | 알갱이 |
| --- | --- | --- |
| 혼 | 1~5 | 3개 |
| 혼 | 6~10 | 5개 |
| 혼 | 11 이상 | 7개 |
| 엽전 | 1개당 1알 | 최대 3알 |

- 화면 전체 동시 알갱이 최대 20개. 넘으면 새로 생기는 몫은 마지막 알갱이에 합쳐 보이게(숫자는 정확히).
- 숫자 상수는 코드에 두고, 플레이해 보고 바꿀 일이 많으면 그때 시트 열로 옮깁니다(지금 시트 안 바꿈).

### 2.4 소리 [제안]

| 소리 | 느낌 | 규칙 |
| --- | --- | --- |
| 혼 도착 | 낮은 바람 "쉬익" + 작은 방울 | 연속으로 닿으면 음 높이를 조금씩 올림(최대 5단) |
| 엽전 도착 | 엽전 "짤랑" | 같은 프레임에 겹치면 1번만 |

### 2.5 아트 리소스

| 리소스 | 크기(1080 기준) | 프레임 | 비고 |
| --- | --- | --- | --- |
| 혼 불씨 | 약 48px | 4프레임 일렁임 반복 | 푸른 흰 넋불. 가운데 흰색, 바깥 푸른 빛 번짐. 도깨비불보다 작고 차가운 색 |
| 엽전 알 | 약 32px | 4프레임 돌기(앞면·옆·뒷면·옆) | 저장 표시 엽전(O06)과 같은 상평통보 그림을 작게. 그림 1장 + 코드 회전도 됨 |
| 도착 반짝 | 약 96px | 4프레임 | 혼용 푸른, 엽전용 금빛 2색(같은 모양 색만 바꿈) |
| 꼬리 | — | — | Unity Trail로 처리, 그림 없음 |

### 2.6 완료 기준

- ☐ 잡몹을 잡으면 알갱이가 튀었다가 막손에게 빨려 들고, 닿을 때 소리와 HUD 튐이 남
- ☐ 날아오는 도중 죽어도 재화는 이미 반영돼 있음
- ☐ 여러 마리를 한꺼번에 잡아도 알갱이가 20개를 넘지 않음

- 저장 순간 효과·UI를 거는 시점: 리깅 뒤에는 **앉기 애니 이벤트**(엉덩이 닿는 키), 리깅 전에는 **F 뒤 667ms 타이머**. 개발이 같은 함수 하나를 두 쪽에서 부르게 하면 리깅이 들어와도 바꿀 곳이 애니 이벤트 하나뿐입니다. [제안]
- 앉아 있는 동안 피격 없음(L08_1 예외 그대로).

### 3.3 앉지 않는 저장

| 저장 | 연출 |
| --- | --- |
| 서낭당 처음 닿아 켜질 때(자동 저장) | 서낭당 켜짐(L08) + 신목 빛 한 번 + 엽전 "기록했다". 앉지 않음, 조작 안 막음 |
| 갈림길 강제 저장(11/25) | 엽전 "기록했다"만 |
| F5 수동 저장(테스트 빌드) | 엽전 "기록했다"만 |

### 3.4 저장 실패

- 저장 실패는 에러 팝업 흐름 2.3(30343, 5초×3 재시도 뒤 "저장하지 못했습니다" → 계속 플레이)을 따릅니다. O06의 "표시 없이 로그만"은 쓰지 않습니다.
- 서낭당에서 실패해도 캐릭터 애니·천 날림·회복은 그대로 하고, **엽전 "기록했다"만 띄우지 않습니다.**

### 3.5 11/26 리젠과의 관계

- 11/26 결정으로 서낭당 휴식 = 맵 몬스터 리젠 시점입니다. 리젠은 저장 순간(667ms)에 같이 처리하고, 따로 보이는 연출은 넣지 않습니다. 금줄 서사("밤이 지남") 연출을 넣을지는 건호 님 서사가 나온 뒤 다시 봅니다.

## 2. 고르는 규칙 (무작위 없음)

몬스터가 대기를 마치고 어그로가 있으면, 패턴 표(MonsterSkill)를 **Priority 순서(1이 먼저)** 로 위에서부터 보고, 아래 조건을 **모두** 만족하는 첫 패턴을 씁니다.

| 조건 | 내용 |
| --- | --- |
| ① 거리 | `MinRange ≤ 플레이어까지 가로 거리 ≤ Range` (지금 그대로) |
| ② HP | 몬스터 HP가 `HpBelow`% 이하 (100 = 항상) |
| ③ 쿨타임 | `Cooldown`이 끝남 — **모든 패턴에 적용**(시작한 순간부터 셈) |
| ④ 같은 층 | 근접 패턴(투척 아님)은 높이 차이 50 이하일 때만. 투척·높이 던지기는 상관없음 |
| ⑤ 기타 | 물러서기는 뒤 공간이 있을 때만(지금 그대로). 공중이면 AirReach > 0 패턴만(4장) |

- 맞는 패턴이 없으면: 근접 패턴 거리보다 멀면 **플레이어 쪽으로 걸어감**(지금 그대로), 이미 가까운데 없으면(쿨타임 등) **제자리 경계**(Idle, 플레이어 쪽 보기) 후 250ms 뒤 다시 판단.
- 같은 몬스터 안에서 Priority는 겹치지 않게 둡니다(DataSheet 검사로 막음).
- 패턴 사이 대기 `IdleMin~IdleMax`는 지금 그대로 둡니다(공격 리듬용. 고르는 데는 안 씀). 이것도 고정하고 싶으면 IdleMin = IdleMax로 맞추면 됩니다.

> 결과: 같은 거리·같은 HP면 언제나 같은 패턴이 나옵니다. 쿨타임 동안만 다음 순서 패턴으로 넘어가므로 플레이어가 순서를 배울 수 있습니다.

## 3. 몬스터별 패턴 표 ([제안] 값)

HP 경계는 모두 **50%** 로 맞췄습니다. "반쯤 깎이면 붉은 패턴을 꺼낸다"가 공통 규칙입니다.

### 허수귀 3001 · 불붙은 허수귀 3003 (같은 표)

| Priority | 패턴 | 흰/붉은 | 거리 | HpBelow | Cooldown |
| --- | --- | --- | --- | --- | --- |
| 1 | 잡기 3203·3206 | 붉은 | 0~150 | **50** | **3000** |
| 2 | 할퀴기 3202·3205 | 흰 | 0~150 | 100 | 0 |

→ HP 절반 전까지는 할퀴기만. 절반 아래로 내려가면 붙자마자 잡기, 그 뒤 3초는 할퀴기.

### 지게귀 3002

| Priority | 패턴 | 흰/붉은 | 거리 | HpBelow | Cooldown |
| --- | --- | --- | --- | --- | --- |
| 1 | 근접(내리찍기) 3204 | 흰 | 0~150 | 100 | 0 |
| 2 | 돌진 3201 | 붉은 | **150**~600 | 100 | **4000** (HP 50% 이하 **2000**) |

→ 붙어 있으면 내리찍기, 떨어지면 돌진. 돌진 쿨 동안은 걸어 들어와 내리찍기. HP가 절반 아래면 돌진이 더 자주 나옴.
- 돌진 MinRange 0 → 150으로 바꿉니다(붙어서 돌진 안 함).
- 쿨타임이 HP에 따라 바뀌는 건 `LowHpCooldown` 열이 필요합니다(8장). 열을 안 늘리고 싶으면 "돌진 4000 고정"으로 둡니다.

### 짐 던지는 지게귀 3004

| Priority | 패턴 | 흰/붉은 | 거리 | HpBelow | Cooldown |
| --- | --- | --- | --- | --- | --- |
| 1 | 근접 3207 | 흰 | 0~150 | 100 | 0 |
| 2 | 짐 던지기 3208 | 흰 | 300~600 | 100 | 0 |

→ 지금과 같음(무작위였던 곳이 없음). 1.5~3칸 사이면 걸어 들어옴.

### 옹귀 3005

| Priority | 패턴 | 흰/붉은 | 거리 | HpBelow | Cooldown |
| --- | --- | --- | --- | --- | --- |
| 1 | 물러서기 3211 | (번쩍 없음) | 0~200 | 100 | 3000 |
| 2 | 높이 던지기 3210 | 붉은 | 300~600 | **50** | **4000** |
| 3 | 투척 3209 | 흰 | 0~600 | 100 | 0 |

→ 붙으면 뒤로 깡총 → 바로 투척(지금 그대로). HP 절반 전엔 투척만, 절반 아래면 3칸 밖에서 높이 던지기와 투척이 번갈아 나옴.

## 4. 플레이어 상태·다수 몬스터 (11/26 확정)

| 규칙 | 내용 | 이유 |
| --- | --- | --- |
| 동시 공격 수 (D1) | 한 플레이어에게 동시에 '공격 중'(예비 동작~후딜)인 잡몹 **최대 2마리**. 자리 없으면 제자리 경계 후 250ms 뒤 다시 판단. 손 떠난 투사체는 안 셈 | 11/25 피격 무적 0 → 여러 마리가 겹치면 피할 틈이 없음 |
| 공중 대응 (D2) | `AirReach`(타일×100): 맞는 순간 근접 판정을 몸 위로 더 늘림. **허수귀 잡기 150·지게귀 계열 내리찍기 150**. 플레이어가 공중이면 AirReach > 0 패턴만 조건 ⑤ 통과 | K4 "점프 난사로 다 피함". 피하려면 구르기·패링 |
| 넉백·구속 중 (D3) | 플레이어가 **허수귀에게 잡혀 있거나 넉백·다운 중**이면 다른 몬스터는 새 패턴 시작 안 함(이미 판정 중인 건 그대로) | 무적 0이라 연쇄 피격 방지 |
| 다른 층 | 근접 안 씀, 투척 계열만 (2장 ④, 확정) | 위 발판 플레이어에게 헛손질 |

| 매달림 | 따로 규칙 없음(11/25: 매달림 중에도 맞고 떨어짐) | |

## 7. 개발 완료 기준

- [ ] 패턴을 무작위로 고르지 않음: 같은 거리·HP·쿨 상태면 항상 같은 패턴
- [ ] Priority 순서대로 조건(거리·HP·쿨·같은 층)을 보고 첫 번째 맞는 패턴을 씀
- [ ] 모든 패턴이 Cooldown을 지킴
- [ ] 허수귀·옹귀는 HP 50% 전까지 붉은 패턴을 안 씀
- [ ] 위 발판 플레이어에게 근접 헛손질 안 함, 투척은 함
- [ ] 잡몹 3마리 이상 붙어도 동시에 공격하는 건 2마리까지
- [ ] 허수귀 잡기·지게귀 내리찍기 예비 동작 중 점프해도 1.5칸 안이면 맞음
- [ ] 허수귀에게 잡혀 있거나 넉백 중일 때 다른 몬스터가 새 공격을 시작하지 않음
- [ ] 보스는 영향 없음

## 8. DataSheet 반영안 (확인 전 안 고침)

`Monster.xlsx` → `MonsterSkill` 탭

| 바꿀 것 | 내용 |
| --- | --- |
| 새 열 `Priority` | 정수 1 이상. 같은 MonsterID 안에서 겹치면 안 됨(@check Unique MonsterID·Priority) |
| 새 열 `HpBelow` | 정수 1~100(%). 100 = 항상 |
| 새 열 `LowHpCooldown` | 정수 ms, 0 이상. 0 = Cooldown과 같음. HP 50% 이하일 때 쓰는 쿨타임 (지게귀 돌진 2000만 씀). 안 늘리기로 하면 빼고 돌진 4000 고정 |
| 새 열 `AirReach` | 정수 타일×100, 0 = 위 판정 없음. 3203·3206 잡기, 3204·3207 내리찍기 = 150 |
| 값 | 3장 표대로: 잡기 3000·돌진 4000·높이 던지기 4000 쿨, 3201 MinRange 0 → 150, HpBelow 50(잡기·높이 던지기) |
| 규칙 칸 | "같은 MonsterID 행은 StateID 순서로 고름", "Cooldown은 물러서기 행만" 문장 삭제 → 2장 규칙 요약으로 교체 |

- 새 열은 스키마 변경이라 클라 `Assets/3.Script/Data/MonsterSkill.cs`도 같이 바뀌어야 합니다(개발). 개발이 열 이름을 확인해 주면 DataSheet에 넣습니다.
- 동시 공격 2·다시 판단 250ms·첫 공격 500ms·같은 층 50은 개발 코드 상수로 둡니다.

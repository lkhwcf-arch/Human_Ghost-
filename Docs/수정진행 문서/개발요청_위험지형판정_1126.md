# 개발 요청: 위험 지형(잔불·얼음) 판정을 그림에 맞추기

작성: 기획 김현호 · 2026-11-26 · 기준: Develop 최신(학원 PC 11/26 아침 Pull, HH_Work = Develop)

관련 피드백: 지스타 #24 "용암(잔불) 범위가 이미지와 다르다", #23 "용암 시인성이 낮다", docx 함정·지형 가독성 5건.
개발 답변 "프리팹 콜라이더 설정을 바꾸면 될 듯?"에 대한 기획 확인 결과입니다.

## 1. 한 줄 요약

- **구덩이(낙사)는 고칠 것 없습니다.** FallZone 5곳 모두 땅 충돌 끝·땅 그림 끝과 딱 맞습니다(그림 2).
- **잔불(지스타에서 '용암'이라 부른 것)·얼음은 플레이어 쪽 판정이 너무 큽니다.** 불 판정 상자는 그림과 같은데, 플레이어 쪽이 화면에 안 보이는 Body 사각형(1.3×1.3칸, 발밑 0.2칸까지)이라 **발이 불 0.15칸 앞에 있어도, 불 위 0.25칸 떠 있어도 맞습니다**(그림 1 위).
- 이건 프리팹 콜라이더만 바꿔서는 안 고쳐집니다. 잔불·얼음 판정은 프리팹 콜라이더가 아니라 코드가 표(FieldObjectPlacement)를 읽어 만드는 상자이고, 플레이어 쪽은 Body 사각형의 그림 범위를 씁니다. Body 사각형은 보스 공격·관문 판정에도 같이 쓰여서 그걸 줄이면 다른 판정도 바뀝니다.

![잔불 판정 지금 vs 수정안](그림1_잔불판정_지금vs수정안.png)

## 2. 지금 어떻게 되어 있나 (코드 확인 결과)

| 항목 | 지금 | 위치 |
|---|---|---|
| 불·얼음 판정 상자 | 폭 = 표 Width(잔불 2칸), 높이 = 고정 0.2칸(`_fieldContactHeightUnits = 20`), 바닥 = 표 Y | `GameplayPreview.Fields.cs` ConnectFields |
| 불 그림 | 같은 상자 폭에 맞춰 늘린 `FieldFire_Debris.png`(384×38px) → 그림 높이도 약 0.2칸 | 같은 파일 ShowFieldAreas |
| 플레이어 쪽 판정 | `_playerBody`(PlayerGameplay 프리팹 **Body**, DebugSquare 4px·PPU 4·배율 1.3 = **1.3×1.3칸**, 중심이 발 위 0.45칸) 의 `SpriteRenderer.bounds` | `FieldEffectTargetBinding.Bounds` |
| 플레이어 이동 충돌 | 반 크기 0.3×0.65 = 폭 0.6칸 | `GameplayPreview._playerHalfSize` |
| 플레이어 그림의 발 폭 | 대기 그림 기준 발 끝이 중심에서 좌우 약 0.5칸 | `1.Idle.png` × 0.7075 |
| 몬스터 쪽 판정 | `GetComponentInChildren<SpriteRenderer>(true)` 첫 번째(지게귀 프리팹엔 PreviewSprite 그림과 Body 사각형 둘 다 있음) | `GameplayPreview.Fields.cs` 39행 근처 |

참고: Body의 SpriteRenderer는 씬에서 꺼져 있습니다(m_Enabled 0). 꺼진 렌더러의 bounds가 실제로 1.3칸 사각형으로 잡히는지 개발에서 한 번 로그로 확인 부탁드립니다. 지스타에서 불 피해가 들어갔으니 사각형 크기로 잡히고 있다고 보고 썼습니다.

## 3. 요청 (기획이 원하는 결과)

원칙: **보이는 것보다 작게 맞는 쪽**(11/25 피드백 정리 #24 추천). 발이 불 그림을 밟았을 때만 피해.

1. **플레이어 쪽 = 발 판정**: 필드 효과(불·얼음)는 Body 사각형 대신 **발 상자**로 겹침을 봅니다.
   - 크기: 폭 **1.0칸**(발 그림 폭, 중심 ±0.5), 높이 **0.3칸**(발바닥 = 발 기준선부터 위로 0.3칸).
   - 방법은 개발이 정합니다. 예: PlayerGameplay 프리팹에 `FieldContact` 자식(BoxCollider2D, 트리거, size 1.0×0.3, offset 발 기준) 을 두고 바인딩이 그 bounds를 읽기. **Body 사각형은 그대로**(보스·관문 판정에 영향 없게).
   - 몬스터도 같은 기준(그 몬스터 발 폭 × 0.3칸). 프리팹마다 `FieldContact`를 두면 몬스터 크기(11/13 1.25배)도 자동으로 따라갑니다.
2. **불 판정 상자 = 그림 안쪽**: 잔불(FIRE_*) 상자를 그림보다 **양끝 0.15칸, 위 0.05칸** 줄입니다. 잔불 2칸이면 판정 1.7칸 × 0.15칸.
   - 그림 양끝 16px(0.08칸)은 불씨가 듬성한 부분이라 거기서 맞으면 억울합니다.
   - 얼음(ICE)은 줄이지 않습니다. 얼음은 넉백 2배를 주는 바닥이라, 구덩이 가장자리까지 붙여 놓은 의도(11/13)를 지켜야 합니다.
3. 수치는 코드 상수 대신 고칠 수 있는 곳에 두면 좋겠습니다(인스펙터 또는 프리팹). 테스트 뒤 기획이 조정합니다.

결과(그림 1 아래): ① 발이 불에 안 닿으면 안전 ② 발이 불 띠를 밟으면 피해 ③ 점프로 넘을 때 발이 불 위에 있으면 안 맞음.

## 5. 같이 보면 좋은 것 (요청 아님, 참고)

- 시인성(#23)은 판정과 별개로 아트 몫입니다. 지금 잔불 그림은 높이 0.2칸에 어두운 숯이라 땅과 잘 안 갈립니다. 불꽃을 위로 0.3~0.5칸 올리고 빛(번짐)을 더하는 안을 아트에 따로 요청할 예정입니다. **그림을 키워도 판정은 위 3번의 발 높이 기준을 그대로 둡니다**(불꽃 끝에 닿았다고 맞지 않게).
- 맵 프리팹의 `Hazard_Fire_M2_x21·x42·x97`, `Hazard_Fire_M3_x21·x86`, `Hazard_x76` 표식은 읽는 코드가 없는 LDtk 시절 표식입니다. 실제 잔불 자리는 표(산길 x23~25, x96~98)입니다. 지우지 않아도 동작엔 영향 없습니다.

# 현재 구현과 검증 현황

기준일: 2026-11-03. 클라이언트 `d8db39b`와 형제 DataSheet의 로컬 코드·데이터를 점검한 결과입니다. 현재는 데이터 공급·개별 모듈 기반을 갖추고 운영 진행을 연결하기 전 단계입니다. 완료율을 검사 개수나 파일 수로 계산하지 않습니다.

기획 규칙은 [기획 확정 반영 기준](기획%20확정%20반영%20기준.md), 개선 판단은 [설계 기준 점검과 개선 방향](설계%20기준%20점검과%20개선%20방향.md), 실행 순서는 [남은 구현과 검증 작업](남은%20구현과%20검증%20작업.md)을 따릅니다. 이 문서는 구현·연결·검증 상태의 기준입니다.

## 1. 전체 연결 상태

```mermaid
flowchart TD
    A[기획자 엑셀] --> B[검사·CSV/JSON 추출·정의 최초 생성·배포]
    B --> C[공통 CSV 다음 나머지 CSV 다음 JSON]
    C --> D[읽기 전용 데이터 저장소]
    D --> E[캐릭터·전투·잠금·컷씬 코어]
    E --> F[테스트씬·일부 화면]
    D --> G[타이틀·저장 모듈]
    F -.연결 대기.-> H[운영 맵·진행 상태·씬 전환]
    G -.연결 대기.-> H
    H -.후속.-> I[스폰·풀링·연출·한 판 완주]
```

실선은 현재 준비한 연결이고 점선은 운영 통합이 남은 부분입니다. 조회 가능한 데이터가 있다는 사실과 실제 콘텐츠가 그 데이터를 사용해 동작한다는 사실을 구분합니다.

## 2. 기능별 현재 범위

| 영역 | 구현한 부분 | 연결·추가 구현·검증이 남은 부분 |
| --- | --- | --- |
| 데이터 공급 | 새 파일·탭 탐색, 기존 탭 규칙 해석, 검사·추출·배포, 정의 최초 생성, 자동 로딩 계획 | 기존 컬럼·생성자 변경은 개발자 동기화. 새 행동 종류 자체를 자동 생성하지 않음 |
| 데이터 초기화 | 공통 스탯 CSV→나머지 CSV→JSON, 준비 완료 후 결과 공개, 취소 수명 | 운영 조립자가 기능별 준비·종료 순서 연결 |
| 스탯·상태 | CharacterStat 추상 상속, 고유 스탯, 상태 클래스와 행동 함수 전환 | 데이터 기반 상태 구성·실제 필요에 따른 복합 상태·상태 팩토리 |
| 전투 | 공격·콤보·구르기·피격·무적·자원, 체세·해체·페이즈·보스 패턴(사슬 Attack3 포함)·매달리기·결박 가르기·약초·착지·낙하 코어 | 운영 물리·센서·히트박스·애니메이션·사슬·변종 고유 동작 |
| 몬스터 | 허수귀·지게귀·불붙은 허수귀(죽을 때 불)·짐 던지는 지게귀(투척) AI, 잡기·돌진·벽 허점, 테스트 구동 | 운영 패턴 선택·관측·스폰·풀링 |

| 타이틀 | 메뉴 규칙·표시·키보드·마우스 입력, 아트 이미지, 저장 유무 조회, 새로 시작→임시 로딩 화면→도화골 테스트 씬, 종료, 테스트 기록 조회·선택 | 인트로 경유, 정식 로딩 그림, 이어하기·설정 실제 실행 |
| 저장 | 슬롯 직접 선택·JSON 파일 교체·조회, SaveGameFlow, 테스트 타이틀·F5 화면·확인창 | 실제 ISaveGameRuntime 구현, 운영 씬·저장 지점 연결, 관문 저장 형식 수정 |
| 잠금 | ContentAccess의 기획자 잠금·플레이어 해금 공통 판단 | 맵 입장·스킬·아이템·몬스터 생성에서 실제 적용 |
| 컷씬 | 빈 Cutscene/CutsceneStep 탭, 검사·배포·로딩·정의 변환·순수 재생 코어 | 실제 행, Addressables·리소스 검사·영상/그림 표시·입력/시간/소리·씬 연결 |
| 맵·진행 | Stage·StageLayer 데이터와 범위가 정해진 앵커 조회 | 운영 맵 JSON·스폰·풀·처치/재방문 상태·씬 전환 |
| 자동화 | 배포 EXE, Develop 검사·개발 알림, 수동 시작 빌드·보관·빌드 알림 | 타이틀 포함 전체 진행 빌드, 출시 빌드 정책, 실제 실행파일 검증 |

버프 효과·추가 무기/인벤토리 등 보류 범위를 완료로 간주하지 않습니다. 로딩은 기획 수정으로 보류하며 스테이지 완성 전 실제 맵 복원 연결도 사용자 지시에 따라 보류합니다.

## 4. 확인한 불일치와 미확인 사항

| 항목 | 현재 근거 | 처리 상태 |
